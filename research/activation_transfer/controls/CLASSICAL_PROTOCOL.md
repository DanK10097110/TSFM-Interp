# Does the second neural forecaster add information beyond a classical reference?

Fixed 2026-11-20 at 17:30 UTC before reading the preceding behavioral scores. A model's response to a recent waveform may track local autocorrelation, periodicity or simple analog continuation. A comparator that consults a trained TSFM can exceed ten scalar input summaries even if an untrained, input-driven forecaster captures that relationship. The previous experiment motivates a stronger baseline.

## Frozen design

Use the same 576 series, held-out splits, perturbations, analysis unit and native median responses as the first experiment. Add a fresh 160-item set from GIFT-Eval bitbrains_fast_storage/H, variate 0 (one channel per virtual machine, seed 975513), omitting the v3 external-real items. Select from histories with 128 finite, nonconstant observations in the same pre-final-16 window. Fix this split before computing new responses. Use only the four primary waveforms for inference; all other edits are diagnostic. Frozen daily calibration predicts every domain.

Build two classical forecasters directly from each edited 128-point history. One fits a direct 16-step ridge autoregression to all embedded lag-16/next-16 pairs in that history (penalty 0.1 times the count, unpenalized intercept). The other finds similar recent trajectories across the same history. It compares centered lag-16 prefixes by mean squared distance, takes a smoothly weighted average of candidate successors with bandwidth equal to the fifth nearest distance, and restores each retrieved trajectory's level to the query endpoint. Distances, bandwidth, weights and autoregressions are recalculated independently on each signed edit, just as the neural forecasters are. No corpus, pretraining or forecast labels enter those two source models.

Remove each model's clean-input conditional mean using the frozen ten-feature ridge. Fit nonnegative coefficients per waveform on calibration for (a) the two classical residual sources together and (b) those two plus the other TSFM source, using least squares over all calibration series and horizons. No hyperparameter selection. Test whether adding the TSFM improves over both classical models plus clean-history summaries, and whether the classical models themselves improve over clean-history summaries. The primary endpoint is the equal-weight mean over the four stimuli of the relative reduction in squared target-response error versus the preceding predictor. Use 2,000 series-level bootstrap draws for a paired interval. Conditional randomization illustrates what shared nonlinear forecast dynamics can explain, but cannot identify a mechanism. Treat the fresh Bitbrains points as the replication check, and report earlier domains as descriptive follow-up. Declare independent corroboration for this setup only if the lower bound of the TSFM addition exceeds zero in both directions on Bitbrains. Report scalar coefficients, gains, input families and separate level and shape diagnostics to expose any concentration of results.
