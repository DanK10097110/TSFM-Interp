# Transfer the horizon shape while leaving forecast level with the destination

Frozen after seeing the first three domains and Bitbrains fast-storage, before forecasting on the new test sources. The earlier Bitbrains direction from TimesFM to Bolt improved horizon-centered shape recovery by 28.6%, yet its full-response recovery against the classical predictor worsened by 29.5%. In Seattle the separate level correction also failed on the original calendar window. This motivates an explicit prediction procedure under domain shift: let the destination's classical predictor estimate the average vertical displacement, and transfer the source model's response only in the orthogonal, zero-mean horizon subspace.

Fit everything on the same 128 original M4 daily calibration cases. Train the ten-feature clean predictor and the two classical corrections separately for each response component (scalar mean, and the 16-lead response minus that mean). For each component also fit an alternative predictor that adds the observed change in the source TSFM to the classical predictors. Build four fixed full-response predictions: (1) both components classical; (2) add the TSFM source only for shape; (3) add it for level only; (4) add it for both using separate component fits. Include the previous single-coefficient, full-vector transfer rule for comparison. The counterpart TSFM supplies forecast outputs on the same stimulus; destination forecasts enter only during calibration and evaluation.

The independent test sources are GIFT-Eval bitbrains_rnd/H, variate 0, 160 new VMs (seed 975516), and SZ_TAXI/15T, 48 new traffic series (seed 975517). Exclude every item used in the earlier external-real panel. Use the pre-final-16 128-point history and the original four stimuli. Freeze IDs before running models. Assess equal-weight mean of the four per-waveform fractions of full response SSE saved against the split classical predictor on each source and direction. Per-series bootstrap 4,000 times using paired resampling of the complete four-waveform record. Declare positive shape-only transfer on all four test cells only if each cell's lower one-sided 98.75% bootstrap bound exceeds zero (Bonferroni control for four cells); preserve ordinary two-sided percentile intervals, competing methods, and prior-domain descriptive results. This criterion tests utility of the chosen projection, not cross-domain universality of any hidden mechanism. Report mean squared error on the same target for all methods. The outcome collection does not tune the projection, dose, method, or threshold.
