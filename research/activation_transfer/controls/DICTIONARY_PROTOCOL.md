# Does SAE geometry help implement an already mapped write?

Prospective follow-up, 20 November 2026. Earlier literal-atom intervention results are available. This control will test the physical recipient forecast effects of four previously unevaluated dictionaries on the same held-out populations. The outcome is recovery of the **dense recipient intervention**. It does not estimate agreement with the original source ablation, and it does not say whether target atoms naturally co-activate.

Reuse the original 1,024 clean M4 daily training histories, 16 randomly selected source atoms per model, their fixed ridge-mapped target directions, the original source firing indicators and coefficients, daily/electricity test cases, 8-step median forecast and unchanged recipient baseline. For each target direction and dictionary, select 1, 4 or 16 axes by the original signed orthogonal matching pursuit (maximum absolute unit-vector residual correlation, followed by least-squares refitting). Subtract the approximation multiplied by the source atom’s original test coefficient. Keep the original dose, and run the actual target forecast on each source-firing case. Compare to the original executed dense mapped subtraction in that same recipient and case.

Use the original target SAE eligibility rule of firing in ≥1% of the clean training histories. All alternatives have exactly as many directions as eligible target atoms (86 for TimesFM and 340 for Bolt). The comparison bases are (i) the leading centered target clean-state PCA axes, (ii) seeded isotropic Gaussian directions, (iii) seeded zero-mean Gaussian directions with covariance equal in expectation to the empirical centered clean target states, and (iv) a seeded rotation among eligible target decoder rows that holds their empirical mean and covariance fixed before unit normalization while changing individual atoms. For (iv), left-multiply the row matrix by an orthogonal transformation that fixes the all-ones vector. Include each basis’s hidden approximation cosine / relative squared error and the post-unit-normalization covariance difference of (iv). This checks whether changes to individual learned atom identities matter beyond the geometry inherited from the SAE dictionary. Broader random-seed variability is not measured. No calibration on receiver forecast outcomes and no test-derived norm correction.

Within each source atom and population, calculate signed energy recovery 1 – SSE / dense-target energy pooled over source-active cases and all eight leads, then macro-average measurable atoms. Repeat after removing each individual forecast change’s horizon mean. Use the original atom scoring requirement of at least one active case and a reference RMS above 1e−5 clean-history standard deviations. Show per-atom scores, cosine, paired differences and uncertainty conditional on fixed bases and trained models using 4,000 draws of complete series. The eight primary comparisons use the full response at 16 terms, original target SAE minus PCA and original SAE minus decoder moment-matched random geometry, for two recipient models and two held-out domains. Publish paired differences with two-sided 95% percentile intervals and one-sided 0.625th percentile Bonferroni lower bounds; other comparisons are exploratory. This is a new control on previously evaluated series and a fixed trained dictionary per checkpoint.
