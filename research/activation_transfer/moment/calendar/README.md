# Does the native forecast work better on MOMENT's original calendar frequencies?

On a deterministic sample of 768 official M4 competition cutoffs, the public masked-reconstruction call from MOMENT-large had higher error than carrying forward the last observation on each frequency. Small and base had still higher errors. This matters for inclusion in a forecasting comparison because the original MOMENT paper reported experiments on these frequencies using a separately supervised forecasting head. An error gap here says nothing about the published Table 3 head's reproducibility. [Original Table 3](https://arxiv.org/html/2402.03885v3#S4.T3) · [Selection and scoring protocol](PROTOCOL.md)

Entries are mean per-series symmetric absolute percentage errors on actual future observations; lower is better. Per frequency, we took 256 series selected by seeded ordering of their IDs using only eligibility of the training history. Median full history lengths were 29, 86.5 and 193. Raw forecasts saw at most the 480 latest observed values. The official evaluation futures begin immediately after the official train cutoff. The MASE denominator uses the entire official training history and its frequency-specific seasonal lag. The local heads fit only on other M4 **daily** series, with 480 observed values, so input length, frequency and level behavior all change. The local terminal head trains on two future patches. Applying that shared output head to the third mask at monthly H18 is an extrapolation. The original MOMENT work restricted target-series membership to address pretraining overlap; this sample uses a different membership rule. Neither sample size nor raw forecasts support a leaderboard claim. [Yearly paired results](results/Yearly_scores.json) · [Quarterly](results/Quarterly_scores.json) · [Monthly](results/Monthly_scores.json)

The large public head exceeded persistence by 14.07 sMAPE points on yearly series (paired 95% bootstrap interval 11.89–16.29), 6.81 on quarterly (5.37–8.26), and 8.49 on monthly (6.52–10.50). Fitting a new linear head on daily data helped some forecasts but did not close those gaps across frequencies.

An independently written loader traced all 768 IDs, past values, seasonal denominators and official futures back to the pinned source files. Twelve ragged histories per frequency, spanning short through long histories, were also run through the individual libraries' public interfaces. The maximum discrepancy across five checkpoints and 180 series/model calls was below 0.000007 history SD. TimesFM used the public forecast interface with the same preprocessing and augmentation flags as our eager decoder. Bolt used its median. All comparisons use point predictions.
