# Can side effects on the other forecast patch be avoided?

The initial transfer study found that a write to the second masked patch can change the first eight steps in a middle block, alongside substantial changes in the next eight. The following follow-up tests whether this spillover is compulsory. Use the fixed native source events, actual finite donor wave, and current receiving early Jacobian. At the first and second masked token, estimate a write restricted to the null space of the receiving second-eight Jacobian; compare the same solve with no constraint and with the wrong history's second-eight constraint. Use a common trust-region radius based on training norm and objective. Also compare the original early-only write shrunk to the protected write's norm (when the protected write is longer, match both to the smaller norm). Physically measure the receiver's finite first-eight waveform and the collateral second-eight RMS, in training input-standardized units. A protected design is explicitly allowed to see *receiver* late gradients, never donor late outcomes. Low late change is the goal of this follow-up and cannot be called a prediction of the donor's continuation. Split genuine donor fires by domain and atom; deterministically choose up to 16 histories per source atom per domain, to distribute model cost across atoms. Report sample counts, actual effect strength, and sensitivity to one-quarter dose.

Final layer known-answer check: on 16 histories per domain, use the same nonzero signed write at each of the last observed patch and the first and second future patches. With the pointwise decoder a write at the first/second future patch should change exactly its own eight output leads with matching within-patch pattern after RevIN, while a final observed write should have zero forecast effect. Run full public inference with live additive hooks, independently from cached replacement states.
