# The same observed patch can support a different deletion effect when the request changes

MOMENT's public short-forecast method creates one future placeholder per eight requested values. With 480 observed values and H8, the last observed token is slot 62 and the future token is slot 63. With H16, the last observed token moves to 61 and the future tokens occupy 62 and 63. All 480 observations fit in both cases. Holding a numeric slot index fixed would turn an edit to a historical patch into an edit to a future placeholder. [Native adapter](../../../../tsfm_lens/tsfm_lens/models/moment_adapter.py) · [Initial protocol](PROTOCOL.md)

We trained the same two dictionaries per size on H16 daily histories, measured an H8 source feature's actual removal on the last observed token, then repeated it in H16. “Same vector” keeps the H8 direction **and dose**, “same feature” recomputes the same feature's natural dose on the H16 observed token, and “same numeric slot” applies the H8 vector at coordinate 62, the first H16 future mask. The scores below compare centered forecasts for the same first eight leads and average equally over sufficiently frequent donors.

Percentage-of-error reductions are sensitive to a small donor response. For small's first daily seed the native ablation RMS (before centering) was .00232 history SD. Replaying on the aligned token produced .00248, but slot 62 produced .01621. In large's first daily seed the corresponding native and aligned RMS were .02693 and .01993. Comparable support-turnover counts across sizes therefore do not determine how accurately the resulting **forecast change** transfers. A change of request changes both encoded states and how subsequent computation reads them. The same ordinary input had identical overlapping outputs within the tested pairs H7/H8, H9/H16 and H17/H24. Moving from H8 to H16 changed the first eight ordinary predictions by a mean .044 history SD in small and .252 in large on the daily cohort. We manipulated the sinusoidal position and whether other tokens could attend to the extra placeholder. Applying both changes on H16 reproduced H8 to numerical precision, including on raw external temperatures. Their signed contributions can oppose each other. ## Which change in the longer request altered the removal itself?

For the first donor seed, we repeated each H8 removal on three modified H16 graphs, subtracting each graph's own unedited forecast. On daily histories in large, native H16 had −.078 shape recovery relative to H8. Restoring H8 positions alone raised this to .599; hiding the extra mask from attention alone gave .029. Applying both recovered the H8 removal waveform to a maximum absolute difference of .00000263 history SD over the entire daily and traffic event archive. In small, corresponding daily skills were .874, .916, .935 and 1.000. Across eligible daily events the RMS change caused by the different request was .00751 history SD in large, versus .00851 for the centered original removal itself. In small those numbers were .00071 and .00228. The larger checkpoint can change how it reads a given hidden direction when the caller changes the requested horizon, even if one writes the very same vector at the corresponding observed token.
