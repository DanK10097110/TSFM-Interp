# Does asking for more future values change what an observed MOMENT patch means?

Frozen before cross-horizon forecasts, encoder contrasts or SAE fits on 22 November. Compare official short forecasts for identical 480 observed numbers with H=7/8, H=9/16 and H=17/24. The two requests inside each pair have the same number of masked patches. At H=8, 16 and 24, the entire 480-value history still fits. A different early forecast or last-observed-token state at adjacent patch counts cannot arise from losing old observations. Both a change in sinusoidal absolute positions and the addition of an attendable future mask token could explain it.

For small and large checkpoints, measure the change in the first eight predictions between H=8 and H=16 on 128 previously selected daily and 128 traffic histories. Separate the effects using a two-by-two counterfactual on the fixed H=16 graph: use the true H=16 or shifted H=8 sinusoidal positions for every token; allow or prevent attention to the second future patch. Read the same first future patch at every setting. All 480 observations, the RevIN statistics and the first future patch's relative position to each genuine input stay fixed. The jointly shifted/masked cell must reproduce native H=8 on leads 1–8, and the ordinary cell must reproduce native H=16, to establish equivalence. Quantify both effects and their interaction in original-series-standardized units. Also report actual next-eight forecast MAE on the separate forecast-quality panel if available, to distinguish sensitivity from predictive harm.

As a sparse control train two TopK SAEs per model on observed middle-block hidden states (60 complete 8-observation tokens) from the same 1,024 disjoint training series using only the H=16 graph. Use width four times the hidden dimension, k=32, 6 epochs and minibatches of 512 (720 updates), identical data for both seeds, no forecast target. Select 16 features using train-only last-observed-patch firing frequency and the existing outcome-blind selection rule. Report held-out fidelity relative to a training mean and 32-component training PCA, feature coverage, and activation/firing changes in exactly the same last observed patch when only the horizon changes. Directly subtract naturally firing contributions from the live state. Compare transferring the H=8 removal vector into native H=16 with using the H=16 feature's own amplitude for the same identity and patch. Evaluate first-eight signed/centered effects, selection-specific frequencies and physical write size with separate checks at unchanged patch count. This phase tests whether comparisons need the forecast horizon in the definition of an activation site. Any selective discovery of a named feature requires an independent history cohort before a semantic claim.

Model size and two time-series domains are declared in advance. The published parameterization might make either factor negligible; both outcomes are informative. Synthetic and literature-derived claims about positional artifacts remain hypotheses until these changes are measured on actual series.

Replay the identical H8 decoder vector at that raw index as a deliberately misregistered intervention. Measure its actual forecast amplitude and shape.
