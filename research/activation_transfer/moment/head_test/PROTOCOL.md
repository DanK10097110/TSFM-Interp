# Can an interior reconstruction task recover a useful forecast head for the published MOMENT encoder?

Opened November 22 after inspecting the poor official small-checkpoint forecasts and its output weight fingerprint. The original zero-shot results are exploratory motivation. The new readouts have not been fitted. Use the same encoder and original-unit forecast graph in all trained-head comparisons. Labels for the primary new head are observed, interior patches with visible context on both sides. No suffix forecast label or benchmark test-series value enters head training, model selection or reconstruction scaling.

Select 1,024 fit and 128 validation M4 daily series by deterministic item-ID hashing, each with at least 480 finite nonconstant samples. Exclude all six-domain quality panel daily IDs, the separate two low-overlap support cohorts, the earlier blind daily/traffic transfer panel, and the project's public external-real benchmark daily IDs. Use one 480-observation history per item. A missing or nonfinite history can be skipped. Source model pretraining overlap is unknown. Sample one contiguous pair of 8-value interior patches in each of four disjoint 15-patch intervals of each series, leaving at least one adjacent patch visible at each end. For training give MOMENT its ordinary reconstruction mask, with all eight patches removed both from the encoder values and from RevIN statistics. Preserve the normal absolute positions. Validate that modifying held-out numbers leaves the hidden features and output unchanged. Ridge-regress each missing eight-value target in normalized units from its own final masked-token state. Share one linear head over positions. Choose ridge on separate item-level interior reconstruction validation only, from a fixed grid. Compare to (i) the published head; (ii) a fitted linear map of its eight outputs, with the same interior labels; (iii) a head fitted after removing the hidden subspace spanned by the published eight decoder rows; and (iv) an encoder with seeded random weights trained through the same linear readout only. Compare to piecewise linear interpolation *for interior holes*. Hold the encoder frozen in every arm. Small is primary, large is the positive checkpoint comparison.

Transfer each fitted head as-is into the public short-forecast H16 graph by replacing only the pointwise final decoder. Fit once on daily; evaluate 8 and 16 leads on the six-domain raw-future panel, two origins per independent series. Report paired series-level error relative to the published predictions, persistence, period-naive, historical baseline selection and Bolt/TimesFM. A head repaired this way is a locally trained reconstruction readout, not an official zero-shot checkpoint. The main target is M4 daily H16 mean lag-1-scaled MAE (including CIs for paired mean differences and ratios); other frequencies, direct H8 and H16 leads 9–16 are secondary. State any prior visibility of official model/naive results. Evaluate an additional post-checkpoint domain if available; such a test is distinct from the primary M4 evaluation.

As a separate task-trained ceiling, fit an identically structured eight-output linear head on terminal pairs drawn only from the training series' 480 historical observations (464 visible, 16 withheld). Use disjoint validation series for choosing ridge by terminal-label error. Compare a direct 16-output linear forecast using the same 464 available raw lags, last observation, and a lag-32 variant. This arm receives explicit forecasting examples. It asks whether the difference lies in the published readout, task supervision, or the pretrained features. All test inputs still use the full 480 observed values and the same native RevIN scaling.

Before training any base-size readout, the official base output head was independently found to have the same exact-zero-bias and orthogonal-weight fingerprint as small. Repeat the same interior/terminal head fitting and test with base on the frozen panel. Large retains a structurally different published head as the comparison. Use the same one predeclared random-encoder seed for the original small comparison, with a second seed as a sensitivity check. For the external test use the already frozen post-release NOAA USCRN station list and observation dates unchanged, with training remaining exclusively M4 daily.
