# Dictionary fitting, physical measurements and replay

All three receiving dictionaries use the same 1,024 M4 histories as the original donor SAE. Each fit sees 60 observed patch states per history from MOMENT-large’s `encoder.block.11` at horizon 16. Width is 4,096 for a 1,024-dimensional state, with positive TopK at 32. Each independent fit uses 720 Adam updates. A fit receives no temperature data, forecast effect or future observations. The two new runs verified the training-array SHA-256 against the original donor fit. The saved epoch losses and training metadata are in `results/fit_2211220{3,4}.json`. [Original training recipe](../../horizon_identity/train.py) · [Two new fits](fit.py)

Only the final observed patch on each training history enters the Pearson matching. For each of the original 16 donors, select the training-eligible recipient with the largest signed correlation. A receiver axis qualifies after at least eight positive fires on the 1,024 training-last patches. For the group, choose 16 distinct eligible unit decoder rows greedily by largest absolute projection onto the residual. Refit all signed coefficients using least squares after each addition, approximating the donor's unit decoder direction. The group remains fixed across test histories. [Original matching](../match.py) · [Pursuit](../groups.py)

The original study captured a firing donor on 669 station/date/atom combinations. A donor firing at eight distinct stations qualifies. This leaves the same 12 donors, 663 cases and 46 stations for all receivers. The target is always the 16-lead physical forecast change after removing the current donor feature from the frozen backbone. In the own-dose single, an inactive matched recipient produces a zero write. In the forced single, use the measured donor norm even if the receiver feature is off. In the group, scale the learned decoder approximation by the true donor activation; its recipient atoms can also be locally off. Transfer results therefore condition on access to the donor coefficient for the latter two policies. None of these interventions uses subsequent observed temperature. [Station sample](../../forecast_quality/post_release/PROTOCOL.md) · [Original donor events and responses](../weather/results/22112201.npz)

Every recipient intervention runs the original nonlinear suffix and native denormalizer on the raw 480-day histories. Original encoder states through block 11 can be shared across identical records. The physical removal is at slot 61. Slots 62 and 63 are the two future patches. The reference and each replacement subtract the same zero-write forecast with identical 24-item batching. For every event the independent float64 projection from the physically modified final-state vectors is saved with the raw prediction. The full-forward check re-encodes individual original histories through all 24 blocks, reconstructs all writes from both SAE checkpoints, uses a separate replacement hook, and compares its difference with the stored event. It covers the first, middle and last events and the first available open and closed matched gates per seed and policy. [Intervention and check](run.py)

For the primary statistic, subtract each effect’s 16-lead mean and divide by the context SD. Compute the reduction in squared error against a zero effect separately for each donor and weight the 12 donors equally. Raw Celsius RMS and pooled skill weight all eligible event/lead cells equally. Three thousand paired resamples draw whole stations, carrying all their dates and donors together. The crossed sensitivity also resamples donor IDs with replacement inside each draw. The same paired draws are used in each method difference. These intervals condition on an individual SAE fit, the fixed dates, and the checkpoint. Receiver seeds use identical cases. [Scoring](score.py)

## Reproduction

The summaries can be recomputed directly from the committed physical waves in `results/`, the original donor archive and the installed repository environment. From the repository root run `python -m research.activation_transfer.moment.dictionary_transfer.more_seeds.score`. The frozen match, group IDs, signed coefficients, decoder vectors and held-out receiver activations are in each `match_<seed>.npz`. Each `<seed>_<arm>.npz` has aligned `rows`, `cols`, `effect`, `hidden_norm`, and `shadow` arrays. The original station/date identities are indexed by `rows`, and donor atoms by `cols`, in the original weather archive. Each `check_<seed>_<arm>.json` records a separate full-forward comparison in °C.

For a full refit and physical replay use the repository Python environment with PyTorch, NumPy and the native MOMENT package, the original geometry capture, checkpoint, NOAA contexts and clean weather capture. Set `TSFM_MOMENT_MORE_SEEDS_CACHE` and `TSFM_MOMENT_MORE_SEEDS_OUT` to new directories to isolate outputs. The existing clean weather file and optional cached full middle states are read from `TSFM_MOMENT_MORE_SEEDS_WEATHER_CACHE` (default `/tmp/tsfm_moment_dictionary_weather_20261122`). `TSFM_MOMENT_GEOMETRY`, `TSFM_MOMENT_CHECKPOINTS` and `TSFM_MOMENT_VENDOR` configure the original captures, checkpoint weights and installed native implementation. Then run `bash research/activation_transfer/moment/dictionary_transfer/more_seeds/reproduce.sh`. [Original capture replay](../weather/reproduce.sh) · [New replay](reproduce.sh)

The two load-bearing tests passed. Replacing the receiver’s native coefficient with the donor’s coefficient made the gating/dose test fail. Replacing equal-donor skill with pooled event energy made the aggregation test fail on an intentionally high-amplitude donor. Both isolated plants produced one assertion failure and one deselected test each. Run `python -m research.activation_transfer.moment.dictionary_transfer.more_seeds.check_plants` to repeat.
