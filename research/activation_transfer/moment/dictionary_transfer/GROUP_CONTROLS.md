# Does using trained decoder orientations matter for a 16-feature group?

Follow-up to successful within-small group substitution. Restrict to the first donor dictionary seed in each frozen checkpoint. Build an orthogonal rotation of all eligible recipient decoder rows from a fixed independent Gaussian QR draw. This keeps the candidate count, all row norms and all pairwise angles intact. Repeat the identical 16-term signed matching pursuit on those rotated rows for each donor direction. Physically apply that approximation, and again after matching its exact write length to the original trained 16-term group. As a second control project the source direction into the top 16 ordinary state PCs estimated from the 1,024 training last-observed tokens. Neither candidate selection nor dosage sees an evaluation response. Test actual early and later signed feature-removal shapes on all original daily and traffic fires. Report hidden approximation, norm and response separately. The rotated basis is one seeded orientation, not a null distribution over dictionaries. Even an advantage over these controls can support a useful trained geometry without identifying 16 individually interpretable concepts.
