# Does the learned group help after matching its geometric accuracy exactly?

The 16-direction receiving group beat a globally rotated and refitted dictionary. That comparison matches the applied length but allows a better angle to the source decoder. Test whether anything specific to the learned group's orientation improves its forecast effect beyond attaining that angle. This is a follow-up after inspecting the donor-dose and receiver-estimated results, before generating these control directions or forecasts. Use the four historically frequent features of the large encoder's first SAE on the already tested 35-station, eleven-date post-release panel. Use the historical receiver group unchanged and the source's actual dose. Evaluate all 385 histories and keep natural source zeros. No recipient output selects a control.

Decompose each group's fixed removal vector into a component parallel to its source decoder and a perpendicular residual. Replace only the residual direction, keeping its length as well as the parallel projection. Use four seeded isotropic perpendicular unit vectors per feature, fixed across all evaluation histories. As a fifth descriptive control use the next nominated feature's real group residual, projected perpendicular to the current donor. All replacements have the same donor alignment, group norm and hidden Euclidean reconstruction error as the learned group (before floating-point rounding). This is a geometric reference available to an investigator who knows the donor; it is a dense write that need not be implementable as a sparse group in the second dictionary.

The primary comparison is equal-feature H16 centered recovery for the learned group versus the mean **score** for the four isotropic controls, keeping the 35 stations and 11 dates as crossed resampling blocks and the four donors fixed. Report the four separate draws, the empirical-residual control, per-atom values, early/late sensitivities and RMS in raw degrees. An advantage specific to learned residual orientation beyond geometry would favor the learned group. A comparable or better random residual would support the simpler interpretation that achieving the appropriate norm and alignment accounts for much of this group's forecast-effect correspondence. A single encoder, four fixed donors and four fixed rotations limit that inference.
