# Which changes in activation space travel between MOMENT checkpoints?

**A map trained on ordinary hidden states transferred part of the large receiver's response to a recent temperature ramp from the small encoder.** The ramp adds −2°C at the start of the final eight days and +2°C at the end, with zero total added temperature. We also tested adding +2°C to all eight days. Every arm started from the same 480 observed daily temperatures at each of 46 USCRN stations and four post-release forecast origins. The map was fitted once on historical M4 series. No paired weather perturbations, forecast labels, or output derivatives were used to train it. The original panel is exploratory. A narrower [confirmation protocol](new_dates/PROTOCOL.md) fixes the direction and endpoint on different stations and dates.

## What is the reference forecast effect?

Give each model the ordinary and the changed history, and record how the last observed patch's middle-layer state changes. In a clean receiving forecast, add **its own** observed change at that single site and measure the resulting 16 temperatures. This is the reference. Run a separate clean forecast adding the donor's change through the frozen state map instead. These interventions keep the other observed patches, future placeholder states at that layer, and the raw history used by reverse normalization fixed. They isolate one path of the input response. The complete input response includes other paths. [Original paired protocol](PROTOCOL.md) · [Whole-input changes and path substitutions](../../input_paths/README.md)

| Donor → receiver | Physical edit | Correct mapped shape, first 8 | Same edit from other station | Other edit at same station | Correct mapped shape, last 8 |
|---|---|---:|---:|---:|---:|
| Small → large | Recent +2°C | .919 | .902 | .455 | .871 |
| Small → large | Rising ramp | .655 | .543 | .140 | .332 |
| Large → small | Recent +2°C | .701 | .622 | −.042 | .782 |
| Large → small | Rising ramp | .261 | −.030 | −2.272 | .335 |

A score of 1 means exact reproduction of the receiving model's own isolated response, and 0 means that a zero edit did equally well. Each eight-lead segment is mean-centered within the history before pooling squared errors in °C. The control edits are rescaled to exactly the mapped vector's norm, independently for each history. For small → large, the ramp beat the other edit by .515 [station bootstrap .294, .823] and the same ramp from another station by .112 [.052, .168]. The corresponding reverse-direction differences were 2.532 [2.184, 2.930] and .290 [.190, .401]. The wrong-edit control was specified after seeing the original large-to-small warming result. ## What makes the positive result interesting?

- The small-to-large map explains .702 of the ordinary last-token variation relative to a mean for that specific position, and .698 of the variation in last-token differences between held-out histories. For the **ramp-induced** change it explains only .043 [−.004, .085] of total hidden displacement energy, yet it recovers .655 of the early forecast-shape energy. Accurate prediction of every hidden coordinate is unnecessary for this endpoint. One interpretation is that hidden errors can concentrate in directions to which this output is less sensitive. [Ordinary states, edit geometry and waveforms](results/small_to_large.json)
- Merely copying the small donor's own forecast change to predict the large receiver's scored −.047 on the ramp. The receiver's full 16-lead isolated effect had RMS .232°C in large versus .018°C in small. The receiving suffix makes a substantial difference to the interpretation of a comparable hidden input change. [Large-to-small archive and size comparison](results/large_to_small.json)
- For the warming step, a different station's edit preserved nearly all the early small-to-large score. A common response to that particular edit accounts for much of its success. History-specific information mattered more for ramps and in the reverse direction. Station resampling on the four-date panel conditions on those four dates. [Matched controls](specificity.py)

## What this says about feature transfer

The same map struggled when asked to reproduce a **donor SAE removal's own forecast waveform** across checkpoints. Here, measuring the same physical input perturbation separately in both models gives an observable target for the receiving state and its forecast effect. These are distinct scientific questions. A learned translation can carry useful information about the receiving model's reaction to a nonlevel perturbation, even when a donor feature's causal waveform changes under the receiving model's readout. This supports using paired input perturbations as anchors when investigating cross-model features. It leaves open which freely learned coordinates implement a shared semantic feature. [SAE removal experiment](../README.md) · [Forecast-sensitive direction controls](../functional/README.md)

On the prespecified small → large repeat at 35 other stations and eleven different dates, early ramp skill was **.669 [.617, .724]** and later skill .426 [.242, .542]. Correct minus equal-norm wrong-edit was .258 [.035, .632] early. A ramp borrowed from another station retained .615, with the paired early difference to the correct station spanning zero. This strengthens the evidence that the map carries information about the kind of input change. [Independent station/date confirmation](new_dates/README.md)


A direct counterpart in two **different architectures** used the old TimesFM and Bolt alignment, frozen before these temperature edits. On the new panel TimesFM → Bolt gave .621 early centered ramp skill versus .471 for the matched-length warming step. A single ramp averaged over the original panel and given each current norm scored .636. Reordering the six interior ramp increments changed the true receiving response, while choosing the right donor order added little early recovery. These controls narrow what can be credited to the shared response. The historical template is prior in study order; some of its calendar dates follow early test dates. This evaluation addresses representation correspondence without an online forecasting deployment constraint. [External cross-family study](../../../shape_transfer/physical_ramp/new_dates/README.md) · [Matched-increment order contrast](../../../shape_transfer/physical_ramp/new_dates/order/README.md)

A calendar-strict sensitivity subsequently allowed each Bolt recipient only the original sites’ ramp vectors from dates **earlier** than its forecast origin. On the 350 histories with an available earlier source date, the past-only common direction scored .650 and the current map .637. Their paired difference favored the common direction by .014 [.003, .025]. This rules out access to future-calendar source inputs as an explanation for that control’s early recovery on these cases.
