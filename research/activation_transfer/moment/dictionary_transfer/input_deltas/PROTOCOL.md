# Does the ordinary-state map transport a shared physical input change?

The same-input hidden-state ridge map achieved high held-out R², yet mapped single SAE directions often failed to reproduce a donor's forecast effect. Test a different use of the same **frozen** map with a target-side ground truth. Give both encoders an identical observable change in the last eight days of a NOAA temperature history. Does the donor's induced hidden-state change, carried through the fixed study map, predict what the receiving checkpoint actually does at the corresponding observed patch?

Use the initial 46 stations × four forecast origins, 480 observations in °C, fixed native H16, last observed token at each checkpoint's middle block. Use both directions, both earlier local input edits (all eight days +2°C, and an eight-day ramp from −2 to +2°C). Only the last observed patch is ever written. Independently measure the actual hidden change of each checkpoint on the changed input. Replay the receiving checkpoint's **own** last-token change into its clean forecast as the reference. Compare a transported donor change, the transported change from a different station on the same forecast date adjusted to the same norm, and an oracle dose control using the true receiving change's length on the correct mapped orientation. Archive the donor's own last-token forecast effect as a separate endpoint. The mean forecast response to changing the entire input is a separately measured quantity.

On all 184 histories report hidden delta cosine and explained displacement energy (relative to writing zero), and real-output recovery of the recipient's *own isolated site response* on early, withheld later, centered and full forecasts. Bootstrap entire stations and report absolute effect sizes. With ordinary data from the old fit roster, also check position-only and last-token R², and accuracy for between-history contrasts at matched patch locations. A shared observed input manipulation supplies an empirical direction in each encoder; no literal counterpart is available for a latent SAE deletion across different weights. Stronger transport for such an edit would restrict the earlier negative result to its tested object. A weak result would directly identify geometric mismatch for these physically named variations. This is an exploratory follow-up motivated by the original weather mediation and large-to-small transfer result.

**Specificity follow-up.** The correct mapped warming direction into small reproduced some of the target effect even when borrowed from another station at the same date. Before examining the reverse direction's results, test whether that reflects a shared direction for the named input change. At each station/date replace the mapped donor direction with the one for the *other* input edit on that same history (+2 step ↔ ramp). Rescale to the exact norm of the original mapped direction. Compare real forecasts to the same target's own isolated last-token change. Report paired station intervals for correct minus wrong-station and correct minus wrong-edit recovery. This is an edit-identity control added after the first direction's result.
