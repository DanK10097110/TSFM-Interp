# Can a cross-checkpoint map distinguish the order of the interior six observations?

On 35 held-out stations and eleven additional origins, a small→large ramp direction beat a warming-step control, and much early recovery could be explained by a generic ramp shape. Before measuring another perturbed input on that panel, apply an edit with exactly the same mean, magnitude, endpoints, range and histogram as the ramp. Reverse only the interior six values of the original eight-value increment. It has the smallest possible linear slope among permutations with these endpoints and is not a smooth ramp. The physical perturbations match in their moments; the resulting histories can differ in variance through their interaction with the original observations.

Use the same unedited historical state map, frozen weights, daily temperatures, site, H16 graph and exact donor-delta norm matching. Obtain the valid receiving last-token reference independently for each input shape. For each case and requested target edit compare the actual mapped donor edit with the other mapped donor edit at the correct vector's length. The two-by-two design tests whether a direction that works because it has the right endpoints also reproduces the alternative waveform. Primary endpoint is the equally weighted mean of the two correct-minus-swapped skills for centered days 1–8, with each target's own total reference energy as denominator. Use paired station/date draws, 3,000 replicates. Report each target separately, raw °C reference difference RMS, next eight leads and uncentered scores.
