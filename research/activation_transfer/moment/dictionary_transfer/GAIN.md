# Does poor atomic substitution reduce to a wrong dose?

Following the first within-small atomic swaps, retain all eligible histories and compute (i) equal-feature geometry and raw per-atom physical effect RMS, (ii) best positive per-atom scalar on these outcomes, explicitly an in-sample optimistic bound, and (iii) a per-atom scalar learned from the other half of the domain's histories, with hash-assigned two-fold cross-fitting. The fixed nonnegative scalar is shared over all leads and all fires of that atom; if no fold contains both training and evaluation firings, mark the atom unavailable for the cross-fit. Also compute a more optimistic nonnegative scalar fitted separately to each event's own waveform, an upper bound on what any dose-only explanation can recover, conditional on this matched direction. This bound still returns zero when the recipient gate is shut. Apply to native and repaired heads and to both ordinary matched target dose and forced donor-magnitude dose. An output-conditioned fit explains loss; it does not qualify as zero-shot correspondence. Report mean, median and count of positive gains/skills across features and a pooled-energy sensitivity check. Results of multiple seed directions do not count as independent model replications.
