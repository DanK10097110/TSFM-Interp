# Can the receiver itself detect when and how strongly to apply a fixed geometric SAE group?

Registered before fitting a detector or examining any detector test forecasts. This is an explicit follow-up on the previously observed poor performance of a literal naturally gated match and the better performance of a donor-dose signed group. Test the same frozen MOMENT-large checkpoint and first SAE donor 22112201 → receiver 22112202. Choose the four *among the original 16 M4-selected donors* with the largest positive-code firing counts measured on the 1,024 paired M4 **last observed patches**, breaking ties by original donor order. Use all 184 subsequent USCRN station/origins, including dates when the donor remains closed. No selection by test outcome, any weather firing or test correlation. Keep the earlier 16-term decoder groups unchanged.

For each of these four atoms train a scalar ridge predictor with an intercept from all 4,096 actual sparse recipient coefficients at its last observed patch to the donor's native nonnegative coefficient. Four separate outputs can share a linear system; the target scale is individual. Permute the 1,024 sorted-by-capture paired training items with seed 26112291, keep the first 768 for fitting and the last 256 for validation. Standardize receiver features by fitting-subset column mean and population SD, set zero-variance features to zero. Ridge loss is mean squared error over fitting items plus lambda times squared slopes, with lambda in {0.01, 0.1, 1, 10, 100}. Clamp a prediction below its threshold to zero and leave other nonnegative values unchanged. Test thresholds are fixed fractions {0, .125, .25, .5, .75, 1} of the median strictly positive fitting dose for that atom. Select each atom's lambda and threshold by smallest unweighted validation dose squared-error across **all** 256 validation items, breaking equal scores in favor of greater lambda then greater threshold. Retain the 768-fit slopes and intercept without refitting. Record train/validation source IDs, counts, selected hyperparameters, validation confusion and model/fit hashes. Do not place a cap on positive predictions after validation.

On all weather histories the detector and natural-match actuator take only recipient hidden state → recipient SAE code and frozen historical model files. Neither the donor SAE, measured test donor codes, nor donor outputs control which test cases get a recipient write. The computed group hidden write is minus the predicted scalar times the fixed signed 16-axis reconstruction of the donor decoder. A zero prediction is the exactly unchanged physical model. Positive predictions run actual interventions at the real last observed token, the released native H16 head and raw Celsius; store every 184×4 candidate waveform including mathematical zeros. Compare the original correlation match at its own native recipient dose/decoder, donor-dose oracle group (score-only), and zero edit. Reference is the actual natural donor decoder removal, exactly zero when donor closed. No recipient fit uses a weather label or donor/native response.

Primary all-history macro-atom centered H16 waveform skill, prior score definition and input-SD normalization, all four atoms regardless of weather firing frequency unless reference has exactly zero energy; disclose coverage. Station-block and crossed station/atom intervals with 3,000 paired draws, descriptive per-atom precision, recall, dose R² and false-positive energy (predicted centered output energy on donor-closed histories divided by total true donor centered energy; also report fraction of candidate-output energy). Accuracy among detected source firings alone is secondary. Compare signed groups with receiver-estimated vs oracle donor dose and existing own-gated single atom. Record a few independent full model replays including at least one receiver-positive true-negative donor case if it exists, and state precision limits. Four training-ranked atoms and one seed direction constitute a conditional test.
