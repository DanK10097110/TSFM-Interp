# Can a mapped TimesFM or Chronos-Bolt state identify native feature gates in the other?

Re-encoding a predicted receiving state worked on fresh M4 daily histories in both model directions. It offered **no consistent advantage** over directly predicting the receiving SAE dose from the same source state. For the 16 historical target features, the exact-gate map reached .706 versus .668 for the direct detector when transferring TimesFM→Bolt, and .588 versus .603 in reverse. Neither paired difference on daily excluded zero. Under a change to traffic or weather, fewer nominated features fired, and model direction, atom selection and scoring weights substantially changed the result. **High support overlap can come from nearly static coordinates.** Bolt→TimesFM on traffic reached 87.8% mean overlap with the receiver’s true TopK at the same time that full-state R² was −.152. Simply predicting the same 32 most frequent training coordinates for every traffic history also reached 87.8%. On weather the corresponding overlap was 91.2% for the map and 88.7% for the static list. In the reverse direction, TimesFM→Bolt improved on the static list more clearly. Its weather overlap was 52.0% versus 27.8%, with .642 hidden R². [TimesFM state diagnostics](results/bolt_to_timesfm_fit.json) · [Bolt state diagnostics](results/timesfm_to_bolt_fit.json)

**Which four targets were chosen mattered.** For the four most frequent *among the 16 nominees*, Bolt→TimesFM on weather had two firing target IDs and direct versus exact-gate skills of .717 and .615. TimesFM→Bolt had three firing and corresponding skills .187 and −.976. Selecting instead the four most frequent in the *entire* TimesFM dictionary produced four targets that fired on every weather history. A fixed training-mean dose already scored .977 on those four against zero, versus .966 for the state map. On traffic the same unconditional baseline and map scored .972 and .986. The fit-only constant comparator was added after observing the high global-four scores. [Complete report for both four-target definitions](results/summary.json)

## How the dose was predicted

For each true direction we used a separate frozen seed-0 target SAE and the same 1,024 ordered M4 histories. Fit rows 0–767 supplied both source/target state pairs and the supervision for the direct competitors. Rows 768–1023 selected regularization and applicable thresholds. The original historical nominations predate this experiment and used all 1,024 rows. Both four-feature frequency screens used only the first 768. No evaluation history entered fitting or tuning. The state representation was the existing final-window mean over Bolt’s two captured tokens (28 and 29) or TimesFM’s single token (14). These directions compare genuinely different architectures using existing per-model dictionaries. [Captures and population definition](../../../shape_transfer/cross_seed_groups/study.py) · [Fitting implementation](run.py)

The full-state ridge selected a single penalty by validation hidden MSE, then ran the actual receiving SAE, including all competitors for its TopK. The direct ridge selected a penalty and nonnegative detection threshold per target using validation dose error. The explicit alternative predicted each candidate’s signed preactivation and the row’s 32nd-highest nonnegative preactivation, then applied that cutoff, choosing per-target penalties by validation dose error. For the raw-input control we normalized all 480 observed values by their within-history mean and scale, then used only the last 32 in the same direct readout. Intervals use 3,000 matched bootstrap draws of independent series on daily and traffic, or whole stations on weather. Four common weather dates and target IDs were held fixed. [Readout calibration](../evaluate.py) · [Dose statistics](score.py)

## What happened to the actual 16-lead weather forecast?

After scoring the dose readouts, we froze a physical follow-up on all 184 station/date histories and the 16 original receiving directions. Each positive source-predicted dose removed that amount in the known receiving decoder direction, including at a genuinely closed receiver gate. The reference was the measured forecast change from deleting the receiver feature at its own actual dose on the same history. All 3,225 nonzero predicted interventions ran through the real forecaster. We subtracted each waveform’s within-horizon mean and scaled by the context SD, then compared with leaving the forecast alone. The largest discrepancy in fresh end-to-end replay checks was .00001574°C.
