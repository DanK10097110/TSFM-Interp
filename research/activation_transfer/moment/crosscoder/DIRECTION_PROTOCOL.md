# Do the crosscoder's own paired directions move the two forecasts similarly?

This companion test addresses a different endpoint from the four fixed target detectors. Once fitted to paired M4 hidden states, each crosscoder has a small and a large decoder vector for each sparse coordinate. A positive finding would mean that pairing the vectors by coordinate predicts which shape of forecast change the other model makes. Ordinary activation reconstruction alone cannot settle that question.

Use the disjoint 128 M4 daily and 128 Monash traffic histories and the two prespecified dictionary seeds. On each history pick the 32 features active from the small view alone. For every such feature, project its two **raw hidden-unit** decoder vectors through the public checkpoints' exact middle-token forecast Jacobians. Center each 16-lead response over time and measure signed cosine. The primary comparison within each history pairs the same coordinate versus the exact mean across the other 31 active large-model coordinates. This preserves the target activation set and input. Report paired differences separately by domain, training method and seed; bootstrap histories. Check whether the sign and ranking persist when each frequently tested atom gets equal weight. Record physical response sizes so that tiny effects remain visible. A target state is never used to select an active feature.

Compare each learned target decoder with a simple alternative for the *same* source vector. Map it through a linear small-to-large middle-block map fit on the first 768 M4 series' 60 paired ordinary patches. Set its norm to the learned target decoder norm. This gives the alternatives identical source forecasts and target intervention lengths. The map has access to paired data but never to test forecast responses. Repeat the crosscoder test for the shuffled-training-pair control. Within-method matched-minus-permuted comparisons are interpretable across methods; the source directions themselves can change across dictionaries.

For finite-dose confirmation, use the standard and masked crosscoders at both seeds. Before viewing direction scores, fix a simple random sample of 32 histories per domain and one uniform active coordinate per selected history; use the same histories, active-rank draws and distractor offsets in both seeds and methods. Run genuine forecast deletions with the source-only coordinate dose. Compare the source waveform with the actual large paired write, the norm-matched dense map, and one active within-history, mismatched coordinate scaled to the same target norm. Quantify both directional agreement and direct waveform reproduction in original series units. These two different forecast heads can assign different gains or temporal roles to directions that describe matched ordinary activations.
