# Does a paired direction preserve a historical patch and a forecast across TimesFM and Chronos-Bolt?

Frozen before collecting the new dictionary outcomes. Use TimesFM 2.5 as source and Chronos-Bolt-small as receiver, with published native H16 median forecasts and the previous middle post-block sites. Real 480-observation histories are already standardized once by the frozen repository study, and both native adapters retain their own normalizations; input probe units are each original history's SD. For the 1,024 original M4 daily histories, use the first 768 by frozen array order to train every crosscoder, probe and ordinary map. Reserve the remaining 256 solely for ridge selection and evaluating dictionary fidelity. Evaluation is endpoint-only on the independent frozen 128 M4 daily histories and 128 Monash hourly traffic histories, separately. Verify raw history and item IDs have no cross-split overlap. No model fitting or tuning on either test domain.

Use all 15 contiguous nonoverlapping observed intervals of exactly 32 values; validate native time-span boundaries on both models. At each physical interval use one 32-sample TimesFM token and the mean of two 16-sample Bolt tokens. The final interval spans input [448,480). Receiving interventions add the same vector to *both clean Bolt tokens*, while TimesFM receives it once. This is a perturbation to the shared mean; a differential Bolt-token change is outside this comparison.

Fit 1,024-coordinate TopK=32 joint dictionaries with the existing MOMENT optimizer, equal-view normalized squared loss, 256-row minibatches, 1,000 updates and two fixed seeds 22112401/22112402. Ordinary joint uses both true views for all training steps. Masked training presents only the true source to the encoder for exactly 50% of steps; decoder supervision still uses both views. Masked-shuffled uses the same masking policy and one fixed derangement of recipient histories, preserving physical patch index. At evaluation only the TimesFM hidden state selects TopK active coordinates. Use all positive current coordinates with equal weight within each history. No target gating or sign selection.

Separately fit linear ridge readouts of the actual 32-sample input interval from each model, and an ordinary dense TimesFM-to-Bolt map from aligned hidden rows. Train on the same 768 histories/all 15 intervals. Choose each penalty on the 256 M4 validation endpoints, from relative penalties 1e-5, 1e-4, 1e-3, .01, .1 and 1, using raw target/reconstruction mean squared error. Report clean endpoint reconstruction for the full patch, its per-patch-mean-removed shape, its level, and its four contiguous eight-sample bin means with their mean removed. These four bin predictions are exact averages of the fitted 32-value readout. A clean low-fidelity probe limits measurable interpretation.

For each current active source decoder direction on test histories measure (1) signed cosine between the two models' induced horizon-centered *probed input-patch* changes, as well as four-bin shape and patch-mean sign agreement, and (2) signed cosine between the two native H16 forecast Jacobians applied to the corresponding directions. Compare correct decoder ID to every other active ID in the same history and to the same TimesFM row translated by the fitted ordinary dense map into Bolt. The primary dissociation contrast is the paired-minus-other improvement on decoded 32-sample patch shape minus the paired-minus-other improvement on H16 forecast shape, on the same active coordinates. Report methods, seeds and both domains separately with 3,000 history-block resamples and descriptive equal-coordinate estimates when at least 8 histories fired. For tests of paired training itself, compare masked paired with masked shuffled; ordinary versus shuffled changes training mode. No attempt to pool distinct task units directly.

Use H16 native derivatives of uniform hidden writes and compare against the archived H1–8 derivatives and ordinary published forecasts. Validate the H16 second half with small symmetric differences. Then physically remove one deterministic source-active feature on each of 32 cases per domain per seed/method (source-only dose), testing the corresponding target direction against a seeded other-active and ordinary-mapped direction at the matched target norm. Report true centered signed cosine, RMS/history SD, physical error and finite-to-linear agreement. These model-to-model forecast contrasts do not use future outcome temperatures or imply that similar patch probes encode the same causal computations.
