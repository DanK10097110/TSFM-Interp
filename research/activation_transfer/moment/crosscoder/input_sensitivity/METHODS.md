# Native input interventions

Each history has 480 observed values. We leave the first 472 fixed. For each of the last-eight pulse shapes we create two histories, adding and subtracting the pulse times the original history SD and the prespecified dose. Seven Helmert contrasts have mean zero and RMS one within the eight-day patch; the eighth pulse changes all eight by the same amount. We run the production MOMENT checkpoint at H16 with its ordinary per-history RevIN, recording the full middle representation at its actual final observed slot. Native normalization may respond to the intervention. The stored M4 and traffic inputs were already standardized by the earlier cohort construction. [Frozen cases and actual perturbations](results/manifest.json) · [Capture](capture.py)

For a decoder direction *d*, its signed response to shape *j* is the dot product of its unit vector with the difference between the positive and negative middle states, divided by twice the actual input amplitude. The seven projections are coordinates of one sensitivity within the mean-zero input subspace. Their ordinary vector cosine is invariant under orthogonal transformations of the shape basis. The separate level pulse supplies a signed scalar. We use the positive decoder direction for both models. [Comparator implementation](score.py)

A source-only clean crosscoder reading determines exactly 32 positive coordinates in each history. Pair each small coordinate with the same-ID large decoder and compare it with the average cosine to the other 31 target axes for that same history. The dense comparator transforms that same small decoder with the correctly paired small→large hidden-state ridge estimated from the first 768 M4 histories. Its target length matches the actual large decoder’s. This normalization has no effect on the shape cosine. The matched mask during crosscoder training makes the masked-versus-shuffled contrast a controlled test of correspondence; the standard joint condition also differs in whether its encoder ever sees a missing input. [Dictionary protocol](../DICTIONARY_PROTOCOL.md) · [State-map definition](../directions.py)

The event average weights each history equally and each of its active features equally. For the feature-balanced estimate we first average a coordinate over the histories where it fired, then average those coordinate means. We report both whole-history bootstrap and crossed history/feature-identity intervals, plus an equal-feature sensitivity restricted to coordinates firing in eight or more histories. The crossed bootstrap resamples the measured same-minus-alternatives outcomes by paired-coordinate ID and history independently with replacement, keeping each event’s bank of other 31 active coordinates fixed and using common draws for paired quantities. Coordinate identity is meaningful only within a fitted dictionary. A norm-sensitive pooled cosine concatenates all seven-vectors before computing the normalized inner product. This gives stronger responses more influence. Exact zero signatures score zero in the signed shape inner product; the summary records their counts and norm quantiles. [Measurements and uncertainty](score.py)

The resulting statistic characterizes how input changes move the hidden state along a particular Euclidean decoder axis. It differs from differentiating the feature’s encoding and from measuring how an imposed hidden write changes the native forecast. A linear state map transports decoder writes, while input-sensitivity projections also depend on the metric and covariance of the receiving representation. An agreement observed here can establish shared physical-input sensitivity without identifying a common latent concept or downstream control function.

## Replay

Use the original repository model environment, off-line MOMENT vendor package, model weights, geometry captures and six fitted crosscoders. Set `PYTHONPATH=/tmp/tsfm_moment_native/vendor:.:tsfm_lens:tsfm_benchmark`. Run the modules under `research.activation_transfer.moment.crosscoder.input_sensitivity` from the repository root in this order.

1. Run `capture freeze` and run `capture small` and `capture large`.
2. Run `score 0.15` and `score 0.075`, followed by `score compare`.
3. Run `audit small` and `audit large`. The audit reconstructs Helmert contrasts independently using SciPy, reverses sign-loop order, lets the entire H16 forecast complete and checks actual projected discrepancies.
4. Run the tests in `test_sensitivity.py`. Run `mutation_check` to repeat the deliberately broken implementations in isolated source trees. In all module commands prefix the module with `python -m research.activation_transfer.moment.crosscoder.input_sensitivity.` and supply its following arguments normally.

All fitted dictionary weights and the fixed state map predate these measurements. Per-history native finite differences are cached in `/tmp/tsfm_moment_crosscoder/input_sensitivity`. The checked-in case archives retain each active ID and its three signed eight-component signatures, ensuring the magnitudes and null comparison can be independently recalculated.
