# Does a shared direction change the readout at its own patch?

The first seed of the matched native forecast-direction test gave near-zero average agreement. This prompted a distinct mechanistic test. MOMENT's public short-forecast call returns a 512-value reconstruction as well as the last 16 of those values as the forecast. The published linear head is reused at every final patch within each checkpoint. A middle-block edit at the last observed patch can reach that same patch's readout through the residual stream; shaping another patch's output additionally requires cross-token propagation. The hidden states of two models might describe the observed patch similarly while downstream propagation differs. This distinction is testable without changing the weights, fitting a probe, or changing the input.

Keep the earlier samples, same source-only code, model weights, negative coordinate dose and matched target write. From the **same native forward pass**, collect the previous observed patch (60), the edited observed patch (61), the first masked forecast patch (62) and the second (63). Compare like lengths of eight. Verify that the two forecasts concatenate to the adapter's public H16 output. Compare the paired target decoder with a same-history active distractor scaled to the matched target norm. For each slot report the within-history paired advantage in signed shape cosine and actual response sizes in history SD. Include the pooled waveform skill so cosine cannot hide a gain mismatch. Report both seeds, domains and shuffled-training controls. Estimates on the reused daily/traffic panels are exploratory.

Retest the frozen comparison on a new calendar year of USCRN histories, with the station/date panel, random coordinate sampling and score fixed before recording observations. As a second exploratory location check, move the source and target edits to the penultimate observed patch, recompute source features there, and compare the response at that patch with the adjacent observed readouts. This checks whether an effect follows the intervention site. The crosscoder was trained on all sixty observed patches. This test measures causal responses of the published reconstruction pathway, including unmasked input reconstruction. It does not measure accuracy against observed future values.
