# Can one model decide when to make a feature edit in another?

We fix the target before fitting. Take the four MOMENT-large SAE atoms nominated by historical M4 firing frequency in the earlier weather experiment, the middle block's last observed patch, and the archived native 16-step forecast change from deleting each atom. A method sees MOMENT-small processing the same history and predicts the nonnegative activation of each large-model atom. We supply its exact large-model decoder direction. This isolates detecting and dosing the event from learning where to write. The target SAE is a fixed measuring instrument trained earlier on all 1,024 historical items. Both checkpoints and these directions are available during development.

## Main comparison

Train paired dictionaries on the first 768 M4 series, with 60 aligned observed patch states per series. Reserve the last 256 for calibration. Use ordinary summed-encoder TopK, a variant where half of training batches encode the small view alone but reconstruct both views, and a control for the latter that permutes the large-model training histories while preserving patch position. Use 1,024 coordinates, TopK 32 and two initialization seeds. Read each dictionary from the small model alone and fit a ridge readout to the four target doses on the last observed patch. Use identical readout calibration for raw small hidden states, an existing independent small SAE, and each crosscoder. A two-view diagnostic can access the true large hidden state and is ineligible for source-only claims. The independent SAE, like the fixed target SAE, was originally trained on all 1,024 M4 histories.

Score all 385 previously studied NOAA histories, 35 stations by 11 dates. These input histories have been used in earlier work, but their labels and forecasts are excluded from fitting and selecting the current methods. Every predicted dose, including a false alarm, changes the recipient through its native graph. The primary endpoint is equal-atom mean centered waveform skill relative to leaving the model alone, with each series normalized by its historical standard deviation. Resample stations and dates as blocks for paired differences. Report dose recovery, event ranking, closed-gate errors, and physical effect sizes. Report both seeds separately. This evaluates reproducing an intervention, not accuracy against actual future weather.

## Mechanistic controls fixed before scoring these methods

1. Fit a ridge map from the small hidden state to the full large hidden state using aligned patches. Run the original large SAE encoder, including its TopK competition, on these predicted states. A comparison using only last-patch training rows controls for the extra patch examples. Measure recall of active coordinates across the entire dictionary, including those outside the four nominations. Compare to the 32 most frequent coordinates at training endpoints.
2. For a cheaper alternative, predict each nominated atom's signed preactivation and the row's 32nd-highest positive preactivation. Apply the predicted threshold, then use the predicted positive activation as the dose. Compare to regressing the discontinuous, already-gated doses from the same inputs. Measure decision errors by the distance to the true gate, with diagnostic access to the target only when scoring.
3. Test whether adding source depth helps before training a multilayer SAE. Use the last observed patch at the first, middle and last small-model blocks, singly and concatenated with equal per-view RMS scaling. Compare the three-view readout with the best single layer selected on M4 validation, and with the small middle layer. All source layers use the same single fixed target site and forecast horizon. Include raw normalized input history and last eight samples as source-free baselines. These are tests of information accessible to the specified readouts.
4. Use the disjoint, existing M4 daily and traffic evaluation series for dose and gate diagnostics. Retain all domains separately. For the core native weather comparison, include the all-patch middle-state map with exact target TopK and the three-layer explicit-gate readout as mechanistic comparators. Additional comparisons prompted by observations should be marked exploratory.
