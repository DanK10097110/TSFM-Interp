# Can output-informed selection find exceptions to weak average forecast transfer?

Near-zero mean response alignment across all active crosscoder features could hide a useful subset. Use the two missing-view-trained paired MOMENT crosscoders. Form a candidate set of source features active in at least 24 of the first 768 training histories. On an existing independent-of-test set of 96 M4 histories with paired native forecast derivatives, score each pair by its mean signed cosine between the **centered first eight leads** at unit dose. Use all 96 histories and select the top eight features before viewing any candidate-specific holdout response. Keep one nonnegative gain per transfer pair, fit by least squares on the same training derivatives with a maximum of four. Matching scores are gain-independent. Report 32 separate calibration histories without selecting again.

Distinguish the value of selection from the value of the learned pairing. Repeat the identical feature search on 16 deterministic derangements of the eligible target coordinates. Preserve each source coordinate's original target norm. The first derangement is also designated for native finite-dose testing ahead of evaluation. Report all candidate, selected native-pair, and selected wrong-pair metrics, including both fixed seeds. Estimate first-eight mean cosine on all held-out daily and traffic histories for each fixed selected coordinate and report the later eight separately as held-out leads. A fixed unit direction is defined even when its feature is closed; report the results on natural firings separately.

On up to eight naturally firing histories per selected axis per domain, draw a deterministic uniform sample, retain the source's ordinary dose, and measure finite small and large forecast changes with the original graph. Apply the fitted gain for the target physical write. Report per-feature coverage and equal-feature as well as pooled waveform recovery against doing nothing. This is a selected, output-supervised transfer control using paired historical derivatives. A high score for arbitrary re-pairings subjected to the same search would limit any claim that the joint dictionary itself identified privileged steering directions.
