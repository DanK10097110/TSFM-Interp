# Observation sources and checkpoints

The six-domain [manifest](results/manifest.json) preserves local Arrow source filenames and file-level hashes, the eligible denominator, selection rules and every observed/future index. The redistributed study arrays are slices of the original archives. Raw target units are preserved.

- M4 is the Makridakis, Spiliotis and Assimakopoulos forecasting competition. Its series span several types of measurements. Daily and weekly series here use Salesforce GIFT-Eval, hourly series use the AutoGluon Chronos mirror. Their native-unit aggregate combines different measuring scales. [M4 data and competition](https://github.com/Mcompetitions/M4-methods), [competition paper](https://doi.org/10.1016/j.ijforecast.2019.04.014), [GIFT-Eval](https://huggingface.co/datasets/Salesforce/GiftEval), [Chronos datasets](https://huggingface.co/datasets/autogluon/chronos_datasets)
- Monash traffic uses hourly road occupancy on the San Francisco Bay Area freeway system. Monash electricity uses hourly client demand from the 2012–14 Portuguese electricity panel. Godahewa, Bergmeir, Webb, Hyndman and Montero-Manso distribute the hourly archives under CC BY 4.0. We select complete raw windows from the Chronos mirror. [Traffic](https://zenodo.org/records/4656132), [electricity](https://zenodo.org/records/4656140), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- We acknowledge Bitbrains IT Services Inc. for the fastStorage virtual-machine trace and the Grid Workloads Archive for its distribution. Shen, van Beek and Iosup described it in *Statistical Characterization of Business-Critical Workloads Hosted in Cloud Datacenters*, CCGrid 2015. This study uses GIFT-Eval's hourly first channel per VM. We verified that target channel 0 is CPU usage in MHz by matching all 721 hourly entries per machine to the original CSV field on three sampled VMs. Median absolute discrepancies were below 0.000002 MHz on all three. One VM had a maximum 1.83 MHz difference from a straight hourly average; its correlation still exceeded 0.9999999997. The percent-usage field has a distinctly different magnitude. [Per-machine unit checks and source hashes](results/bitbrains_units.json). [Trace provenance](https://atlarge-research.com/gwa-t-12/), [GIFT-Eval release](https://huggingface.co/datasets/Salesforce/GiftEval)
- The later temperature panel uses NOAA NCEI US Climate Reference Network daily product CRND0103, snapshot of November 16, 2026, field 9 T_DAILY_AVG in Celsius, with source missing value −9999 ignored. The four target intervals include observed temperatures only. The station-specific climate is estimated from observations during 2008–23. Users should cite Diamond et al. (2013), *U.S. Climate Reference Network after one decade of operations*, Bulletin of the American Meteorological Society, 94, 489–498. NOAA's data policy places publicly released internal data under a public-domain dedication. The geographic subset and the climate/imputation calculations are ours. [NOAA archive](https://www.ncei.noaa.gov/access/crn/products.html), [USCRN reference](https://doi.org/10.1175/BAMS-D-12-00170.1), [daily field documentation](https://www.ncei.noaa.gov/pub/data/uscrn/products/daily01/README.txt), [NOAA data policy, Appendix E](https://www.ncei.noaa.gov/sites/default/files/2025-04/NAO_212-15B-Data_Mgt_Handbook-2024-Oct-1_destinations_2025.pdf%23.pdf)

The first six sources predate current foundation checkpoints. Chronos's mirror contains both training and evaluation datasets and represents named configurations as a “train” split. The MOMENT Time-series Pile includes public forecasting data, and TimesFM discloses use of selected public archives. The panel is held out from this experiment; its archive membership cannot certify checkpoint-level zero-shot evaluation. The dated NOAA targets address that limitation for one variable and four origins. [MOMENT](https://moment-timeseries-foundation-model.github.io/), [Chronos dataset card](https://huggingface.co/datasets/autogluon/chronos_datasets), [TimesFM release](https://huggingface.co/google/timesfm-2.5-200m-pytorch)

The MOMENT small/base/large artifacts use frozen reconstruction heads with the official short_forecast path. The separate model-card forecasting head is initialized for task-specific fitting. The public small revision is 411e288267f82cce86296dbe4d6c8bc533cc162f, base 5e44b0ea26376a176360f87831124e018f876d96, large ca58581bc7bea2ebed4e80dc0a3e4b8b609c6ecc. The original small-weight commit is dated October 10, 2024. Later small commits through the pinned revision edited the README. I found no published maintainer account of the orthogonal small/base head, nor a separate harmonized eight-/sixteen-lead tuned task checkpoint in the public AutonLab catalog. The early research-repository README contains a classification example using the name AutonLab/test-t5-small. [MOMENT-small history](https://huggingface.co/AutonLab/MOMENT-1-small/commits/main), [base](https://huggingface.co/AutonLab/MOMENT-1-base), [large](https://huggingface.co/AutonLab/MOMENT-1-large), [organization models](https://huggingface.co/AutonLab), [research code](https://github.com/moment-timeseries-foundation-model/moment-research)

Weight-level histories date the last listed TimesFM safetensors update to October 1, 2025 and the Bolt-small archive to November 13, 2024. All registered weather targets start in 2026. NOAA data are from a later quality-controlled snapshot, so this is a retrospective post-release evaluation with observed prefixes, rather than a replay of each operational station feed as published on that day. [TimesFM weights history](https://huggingface.co/google/timesfm-2.5-200m-pytorch/commits/main/model.safetensors), [Bolt weights history](https://huggingface.co/amazon/chronos-bolt-small/commits/main/model.safetensors)

A direct search of the official GitHub issue inventory identified a prior independent observation that the public small/base reconstruction heads perform poorly. On October 18, 2026, issue 87 reported near-zero visible sine reconstruction correlations for the smaller releases, strong large reconstruction, and a held-out patch R² increase from −0.232 to 0.904 after fitting ridge to frozen base states. It includes the exact large weight hash and small revision used here. The issue closed November 20 with state reason “not planned” and no comments in the November 22 API record. This is the reporter's empirical result. The release procedure is undocumented in that thread. Our raw-forecast panel, pretraining-initializer Gram comparison and post-release weather analysis independently assess the implication for short-horizon model selection. [Prior empirical report and reproduction code](https://github.com/moment-timeseries-foundation-model/moment/issues/87)

The subset-level NOAA data citation is Palecki, M. A., J. H. Lawrimore, R. D. Leeper, J. E. Bell, S. Embler and N. Casey (2013), *U.S. Climate Reference Network Products*. We use 46 contiguous-US stations from daily01, T_DAILY_AVG, with the fitting and evaluation dates recorded in the station manifest. Accessed November 22, 2026. [Dataset DOI and use constraints](https://doi.org/10.7289/V5H13007)
