# The native MOMENT forecasting and intervention path

The registered `moment` adapter uses the public reconstruction head and the authors’ `short_forecast` function for both ordinary predictions and differentiation. On CPU float32 its forecasts matched the directly loaded public package exactly on all 12 input-length/horizon cases tested with each of MOMENT-1-small and large. Across small, base and large, the package also matched the original paper implementation at the patch embedding, first/middle/final encoder blocks, decoder and raw forecast. The small and base reconstruction heads have an initialization-like fingerprint in the published files themselves. Changing library era, serialization format or switching to the paper implementation gives no evidence of a fix. [Adapter checks](verification.json) · [Original implementation replay](paper_current_versions.json) · [Weight audit](release.json)

## Calling the model

Use `adapter: moment` and a local pretrained directory or a pinned Hugging Face ID. Omitting the checkpoint selects the verified public large revision (about 1.39 GB of weights). Known public small, base and large IDs use the listed pinned revisions unless an explicit revision is supplied. `predict(x, H, [.1, .5, .9])` accepts raw `[batch, time]` data and returns `point[batch, H]` and three identical point forecasts in `quantiles[batch, H, 3]`. `predict_differentiable(x, H)` runs the same graph with autograd enabled for hidden interventions. No native forecast uncertainty can be inferred from the repeated points. Float32 and CPU are the verified operating conditions. [Large forecast and SAE workflow](WORKFLOW.md) · [Small point-forecast configuration](../../../../tsfm_lens/configs/moment.yaml) · [Code](../../../../tsfm_lens/tsfm_lens/models/moment_adapter.py)

For a dedicated environment, the Lens extra is `python -m pip install './tsfm_lens[moment]'` from the repository root. Upstream pins NumPy 1.25.2, Transformers 4.33.3 and Hugging Face Hub 0.24.0. In the shared Python 3.12.13 environment used for the multi-model experiments, we kept the environment's NumPy 2.1.0, Transformers 4.57.6 and Hub 0.36.2 and isolated the official MOMENT wheel. With those libraries and Lens already installed, the equivalent shell setup is below. The model's default is the pinned large Hub revision. [Original dependency metadata and verified state tensors](release.json) · [Installed-wheel default forecast check](packaged_install.json)

```bash
moment_package_dir="$(mktemp -d)"
python -m pip install --no-deps --target "$moment_package_dir" 'momentfm==0.1.4'
export PYTHONPATH="$moment_package_dir${PYTHONPATH:+:$PYTHONPATH}"
```

- The latest 512 samples are eligible. Short histories are left-padded and the padding is excluded from RevIN. Finite input points determine the raw mean and standard deviation. Normalize before shifting, write a whole number of future mask patches, then reverse the single native normalization on the forecast. Repeated quantiles and all native H from 1 to 512 return the requested length, including a partial final patch.
- `patch_layout(L, H)` returns contiguous observed and future slices on the **live 64-token axis**. With `L=480,H=16`, the slices are `[2,62)` and `[62,64)`. The last 32 observed steps occupy `[58,62)`. The standard activation store reports just the 60 observed slots. A patch containing a nonfinite observation is excluded as an attention key by the native mask. Item-specific missingness can occur anywhere within the contiguous observation layout. At `H=505…512`, every token is a future mask and raw context contributes through RevIN only. The observed-token SAE workflow then has no positions to fit or ablate.
- Above 512 we chose a documented extension using successive 256-step native calls, feeding predictions back as context. `H=513` exactly matched an independent `256+256+1` native rollout. For graph-enabled recursive forecasts, later RevIN mean and scale depend on generated values. The adapter restores their chain-rule terms, which the official single-call layer detaches. For a physical write confined to the first chunk, maximum relative differences between autodiff and centered finite differences over three milestones were 0.00105 small and 0.00010 large. The ordinary raw forecasts stayed bitwise equal. [Physical H513 gradient replay](rolling_gradient.json) The activation extractor records the first call. A live hook left active throughout a recursive forecast can write on later calls as well. For single-call interventions, use the same H for the capture, write and measurement.
- The final block sends the masked future positions to the point decoder. For a physical additive direction, writing to the recent observed positions of the final block had exactly zero effect on both checkpoints. The same test at the middle observed positions and at the final future positions had nonzero actual effects. Autograd agreed with centered finite differences at the middle to relative errors 0.00178 and 0.000483 for small and large. [Actual intervention traces](verification.json)

## Why the small and base heads deserve separate treatment

| Public release | Strict state keys in original model | Max absolute entry of \(WW^T-1.41^2I\) | Bias norm | Median adjacent-row cosine |
| --- | ---: | ---: | ---: | ---: |
| Small | 80 | 0.000000592 | 0 | approximately 0 |
| Base | 116 | 0.000000698 | 0 | approximately 0 |
| Large | 224 | 1.310 | 0.02997 | 0.7093 |

Here `W` is the 8-by-hidden-width public reconstruction matrix. Small and base have precisely the geometry expected from the official output-layer initialization through float32 rounding. This identifies a tensor property, not its training history. The other modules do show changes from initialization. The mask embedding norms are 2.91 and 3.16 respectively, and all 75 small encoder tensors differ from the canonical Google FLAN-T5-small state. The separate published PyTorch `.bin` and safetensors files agree on all 80 small tensors and all 116 base tensors. [Audited tensors](release.json) · [Paper authors’ model implementation](https://github.com/moment-timeseries-foundation-model/moment-research/blob/3ab637e413f35f2c317573c0ace280d825c558de/moment/models/moment.py)

The paper-repository and PyPI versions have identical hidden and forecast outputs for every tested cell within each runtime. Four synthetic raw series were evaluated at 480/H8, 477/H17 with a missing value, and 512/H64. Replaying under PyTorch 2.0.1 / Transformers 4.33.3 and PyTorch 2.12.0 / Transformers 4.57.6 changed raw forecasts by at most `7.63e-6`. Eleven architecture fields in each release agreed with the corresponding original FLAN-T5 configuration. The original fine-tuning helper has a `do_not_copy_head` option, used for a new long-forecast head. Its use during export of the public reconstruction checkpoints is unverified. The authors’ Table 3 evaluated a source-trained forecasting head on yearly, quarterly and monthly M3/M4, using the respective competition horizons of 6, 8 and 18 and M4-style sMAPE. The M4 targets used a matching-frequency FRED source. Appendix F.1.2 describes 40% of items held out from pretraining. Our public reconstruction-head forecasts and fitted reconstruction readouts are separate tasks. [Original-runtime replay](paper_author_versions.json) · [Cross-version replay](paper_current_versions.json) · [Fine-tuning helper](https://github.com/moment-timeseries-foundation-model/moment-research/blob/3ab637e413f35f2c317573c0ace280d825c558de/moment/tasks/base.py#L206) · [ICML paper](https://proceedings.mlr.press/v235/goswami24a.html) · [Forecast-quality design](../forecast_quality/PROTOCOL.md)

An independent October 2026 issue already reported much poorer visible sine reconstruction from small and base than from large, and a successful frozen-encoder ridge readout for base. Our archive fingerprint, original-runtime replays and actual-future evaluation extend that evidence. The issue author and these experiments cannot establish the precise upstream training or export event. [Public report](https://github.com/moment-timeseries-foundation-model/moment/issues/87) · [Independent small readout replay](../head_test/independent/README.md)

On six synthetic histories (7 to 480 observations) and native H6–H18, zero padding and the paper repository’s edge padding gave identical raw forecasts on all three checkpoints under the same mask. Its original data utility applies a configured `last` crop as `timeseries[:seq_len]` for long inputs. Our adapter explicitly uses the most recent 512 observations. [Padding replay](padding.json) · [Original data utility](https://github.com/moment-timeseries-foundation-model/moment-research/blob/3ab637e413f35f2c317573c0ace280d825c558de/moment/utils/data.py#L57)

Each pinned Hugging Face ID/revision in these examples was also loaded through the ordinary Hub mixin using an isolated offline Hub cache containing its official archive. Every live state tensor and its output shape were checked. [All three Hub load results](hub_examples.json)

## Reproduction

Run from the repository root with `tsfm_lens` on `PYTHONPATH`. The optional `moment` extra installs official `momentfm==0.1.4`, whose declared dependencies pin NumPy, Transformers and Hugging Face Hub. We used an isolated extraction of that wheel with the existing project environment and separately tested the package’s original versions in a Python 3.11 environment. The wheel SHA-256 is `3ddf7b6b034a9fda406d759daf1e23b757565e22ebf2d0804de30ad324bfd165`. Each model directory below requires its `config.json` and `model.safetensors`. The release comparison also uses the separately published small/base `pytorch_model.bin`, Google `flan-t5-small` safetensors and all three FLAN configurations. [Official PyPI package](https://pypi.org/project/momentfm/0.1.4/) · [Small snapshot](https://huggingface.co/AutonLab/MOMENT-1-small/tree/411e288267f82cce86296dbe4d6c8bc533cc162f) · [Base snapshot](https://huggingface.co/AutonLab/MOMENT-1-base/tree/5e44b0ea26376a176360f87831124e018f876d96) · [Large snapshot](https://huggingface.co/AutonLab/MOMENT-1-large/tree/ca58581bc7bea2ebed4e80dc0a3e4b8b609c6ecc)

```bash
export PYTHONPATH=".:tsfm_lens:${PYTHONPATH:-}"
export OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 HF_HUB_OFFLINE=1
cache=/tmp/tsfm_moment_native
study=research/activation_transfer/moment/adapter_check
python "$study/verify.py" --small "$cache/small" --large "$cache/large"
python "$study/release.py" --root "$cache"
python "$study/mutations.py"
python -m pytest -q tsfm_lens/tests/test_moment_adapter.py tsfm_lens/tests/test_capability_tiers.py tsfm_lens/tests/test_capability_matrix.py tsfm_lens/tests/test_adapter_conformance.py
```

To repeat the cross-version paper replay, check out `moment-research` at `3ab637e413f35f2c317573c0ace280d825c558de` in `$cache/research_src`. Supply canonical Google FLAN-T5 configurations in `flan_small`, `flan_base` and `flan_large` at revisions `0fc9ddf78a1e988dac52e2dac162b0ede4fd74ab`, `7bcac572ce56db69c1ea7c8af255c5d7c9672fc2`, and `0613663d0d48ea86ba8cb3d7a44f0f65dc596a2a`. Run the first command in the original runtime and the second in the current project runtime. The experiment replaces the original model constructor’s initial text-weight download with a configuration-identical T5 encoder, then strictly overwrites every parameter and persistent buffer with the actual MOMENT release before prediction. Numeric outputs are also saved in compact NPZ files.

```bash
python "$study/paper_replay.py" --root "$cache" --research "$cache/research_src" --output "$study/paper_author_versions.json"
python "$study/paper_replay.py" --root "$cache" --research "$cache/research_src" --output "$study/paper_current_versions.json" --reference "$study/paper_author_versions.npz"
```
