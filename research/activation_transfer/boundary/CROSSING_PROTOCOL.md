# Bracket a TopK crossing on the actual input path

The first experiment found that freezing support helps on measured finite differences, conditional on a change of selected atoms. Test that geometric explanation directly on model-generated states as the input distance tends to zero near an observed crossing. Use the archived Bolt, TimesFM and Chronos-2 dictionaries and the already evaluated weekly cohort. This is an exploratory within-trajectory diagnostic, conditional on a crossing; the unconditional rates come from the original dose experiment.

On each history whose .03 SD pulse or sine changed any active ID, choose the pulse when it crosses and the sine otherwise. Keep the first 32 eligible independent histories in the frozen item order, or all if fewer. Run the actual frozen model at the midpoint along the observed input trajectory. Maintain a lower endpoint whose active set matches the clean state and an upper endpoint with a different active set. Repeat 12 bisections, recording bracket widths after 4, 8 and 12. This construction brackets at least one change even if multiple changes exist. It need not locate the first crossing in a nonmonotone trajectory. Use the original eight-item batching and CPU float32. Primary measurement is the hard-decoded, shoulder-decoded and dense displacement norm divided by the original full-dose dense displacement norm. Report the change in their ratios across decreasing input widths, using equal item weighting. Record actual input RMS and repeat-forward noise at each final endpoint, threshold-score size, exchanged-atom counts and decoder cosine for simple swaps.

At the narrowest bracket, use the low-side history and hidden states to patch its actual dense displacement and the hard and soft decoded displacements into the frozen model. Check the native and no-edit replays. Report median and mean 8-step forecast RMS induced by these patches and by the actual low-to-high input edit, expressed in original clean-history SD. Treat forecast effects near the float32 noise floor descriptively. This local conditioning selects an unusual point on each real background, so its effect sizes should not be interpreted as the typical effect of an arbitrary small input change.
