# Can a continuous sparse encoder recover transfer?

Follow-up designed after the initial M4 and Bitbrains hard-gate results. These prior results suggested that freezing the clean support restores cross-model prediction. This alternative is a standalone encoding of each state, so it needs no remembered clean support.

For preactivations a, sort the ReLU outputs r in descending order. Set the lower threshold t to rank k+1. Let the shoulder end u be rank k/2 (16 of 32). Replace every top-k coefficient z by z times clip((z-t)/(u-t),0,1). The largest half stay unchanged; coefficients near the gating threshold go continuously to zero. If the thresholds coincide, use a deterministic tiny positive width and report degeneracies. The rank threshold is measured separately on each state. No learned weights, new training data, or forecast labels enter this change. For nondegenerate rows it retains the same nonzero feature IDs as ordinary TopK. A second a priori arm uses nonnegative threshold subtraction, max(r-t,0). Its amplitude changes all active coefficients. There is no bandwidth search. Reuse the original dictionary's decoder without refitting it.

Primary follow-up outcome is each smooth arm's mean test cosine gain over hard TopK, for the same rank-32 map of source code differences to the other model's dense state change. Fit on M4 training items, choose ridge on its original validation split, evaluate on M4 and Bitbrains. Report both directions, unchanged support fraction, per-state reconstruction FVU, native finite-difference accuracy, forecast response and pooled relative RMS error. Include raw input, raw dense, shuffled and anchored-support results from the original. Use an additional fresh GIFT-Eval M4-weekly item set (pre-hash and exclude the historical external-real item IDs, latest 480 observations, 80 items if available, no imputation) for an untouched test of this follow-up. Comparisons across methods use paired bootstrap by item. Original M4 and Bitbrains support mechanism diagnosis only for this additional hypothesis; the weekly holdout tests its transfer to previously unexamined series. Datasets can share M4 sampling practices and TSFM pretraining provenance.

### Decoder calibration follow-up

Post hoc, after observing absolute clean reconstruction changes. Each candidate encoder changes mean coefficient amplitudes, while its decoder still has the bias trained for the original hard codes. Estimate a constant mean residual from the 128 clean M4 calibration-history states at this layer and add it to each reconstructed state. Compare uncalibrated, bias-only and global scalar-plus-bias ridge-free least-squares calibration for hard, shoulder and subtraction codes using exactly those same training rows. Test clean reconstruction FVU separately on the frozen evaluation cohorts. A fixed additive bias cancels in code-difference decoding, so by construction this simple recalibration preserves all prior transport/forecast results. This test distinguishes a mean shift in the reconstructed state from a lasting loss of its variation; all three cohorts have already been observed for other outcomes.

### Amplitude and ordering controls

Post hoc, after the three datasets' smooth-code state results. A smooth encoder also changes the norm of a representation and the winner ordering at its boundary. For each clean and edited state construct a still-discontinuous control hard_code × L2(smooth_code)/L2(hard_code), so its norm exactly matches that of the corresponding shoulder or subtraction encoding. Fit and test new maps under the identical M4-only protocol. Also compare an antisymmetric union-support derivative: take the actual ReLU coefficient differences, keeping any atom active at either endpoint. This has at most 2k active coordinates and can use both endpoints. These controls diagnose possible explanations; existing cohorts are reused and the union arm has a larger possible support than the per-state smooth arms.

### Correcting the decoder with a small clean-state calibration set

After bias-only calibration left a substantial TimesFM clean FVU penalty, fit a general affine ridge correction to the original decoder residual using the same 128 clean M4 training histories. Keep all learned encoder weights and gating rules fixed. Use all up to 127 centered calibration directions. Include the original hard encoding under the same decoder-refit procedure. Select a trace-scaled ridge coefficient from the primary grid by 48-item validation clean-state MSE. Evaluate clean FVU and native finite-difference decoded cosine on the three previously studied cohorts. Quantify decoder rotation for calibration-active atoms. This exploratory procedure uses the model's dense activations as calibration targets and can change the semantics of a decoded atom edit. Cross-model predictions that operate directly on the fixed codes are invariant to this decoder-only operation. No forecast outcome enters the decoder fit.
