# Boundary sensitivity of frozen time-series sparse autoencoders

Prospective protocol, 20 November 2026. Recorded before outcome extraction. This is a public development study, independent of the repo's sealed confirmation epochs.

## Question

A TopK encoder can switch dictionary atoms near an ordering boundary. Its decoded change can then point away from the dense change even when few atoms switch. Is this a material source of error on realistic histories, and does using the dense change preserve more information about a second model? High reconstruction fidelity for the original states alone cannot answer either question.

## Material

Use TimesFM 2.5 at stacked_xf.10 and Chronos-Bolt-small at encoder.block.3, the near-middle blocks with saved v3_ablcheck public-development dictionaries (ReLU TopK). These choices precede outcome inspection. Both dictionaries were trained on 32-step window means. Use the final aligned 32-step window in a 480-step, standardized context for every representation comparison, dropping special tokens as in the original runner. This is a comparison at one preselected depth pair. Record checkpoint and dictionary hashes, software versions, and exact source items.

Select one nonconstant finite context per GIFT-Eval M4-daily item with numeric ID >=2000, excluding all M4-daily items appearing in the repository's separate 800-window external evaluation. Use the last 480 observations, hash-sort eligible IDs with study salt boundary-m4-20261120, skip duplicate standardized contexts, and take 256 distinct items. Hash order assigns 128 training, 48 validation, and 80 test items. All perturbations to an item share its split. No official sealed split is opened. Historical or pretraining exposure of the original TSFMs cannot be excluded.

## Edits

Perturb the last 64 observations of each clean, standardized history with either a smooth localized pulse or a tapered sinusoid. Use an item-determined pseudo-random pulse center/width/sign or sinusoid period/phase, a taper vanishing at both endpoints, and unit RMS over the last 64 points before scaling. Run positive doses 0.01, 0.03 and 0.10 in clean-history SD. The middle dose is primary. Repeat the unedited batch for the numerical floor. For a scale reference, also compare codes to an unrelated same-position history. Use both shape families in the primary mean, with each item receiving equal weight.

## Within-model primary endpoint

Let h and h' denote a matched clean and perturbed state, p' the continuous SAE preactivations for h', z and z' the natural sparse codes, and M the clean active set. The local, fixed-support code uses relu(p') on M and zero elsewhere. Decode code *differences* to eliminate the decoder bias. Compare natural and fixed-support decoded change against the true h' - h. Report the difference of mean per-item directional cosines, fixed minus natural, with 95% paired item bootstrap intervals (4,000 draws). Provide the fraction of features replaced, probability of any switch, gain along h' - h, relative RMS error, reconstruction fidelity on clean states, and conditional statistics for switch vs retained support. Identity, train-only rank-k PCA projection, and another series' code are controls. The fixed-support contrast measures the cost or benefit of the top-k decision on this finite difference. Errors left by freezing support can come from other aspects of the dictionary. For each model, call the boundary loss detectable if the lower 95% interval of fixed-minus-natural cosine exceeds zero; interpret multiple dose and subgroup summaries descriptively and disclose that the two primary intervals are marginal.

## Cross-model endpoint

Train a linear map from the source history's perturbation response to the target's *dense* response, using paired calibration series at dose 0.03, separately in each direction. Compare raw dense, natural SAE code, frozen-support code, decoded natural, decoded frozen-support, raw input change, and a within-shape-family permuted dense correspondence. The target is the same for every arm. Use rank at most 32, train-only centering and singular bases, a trace-normalized ridge penalty selected on the same validation grid for every arm, then measure held-out per-item signed cosine (zero prediction scores zero), gain and relative error. No target states from test items enter a fit. Hold the two models' raw coordinates separate; the fit learns a correspondence, rather than assuming an ordering for features. The primary cross-model contrast is dense-input cosine minus natural-SAE-code cosine on the same 80 test items. This contrast measures latent prediction, not forecast agreement. We will separately report whether freezing support recovers part of that difference. Also report held-out zero-response denominators and per-method projective scale.

## Stress tests

If a fixed-support advantage appears, test whether it predicts a change in the *forecast*. On the same test cohort, at the primary dose, inject the final patch's dense change, natural decoded change or frozen-support decoded change additively into the original activation. This holds the original reconstruction error fixed. Compare the eight-step median forecast changes against the dense-patch effect, with the zero patch as a numerical control. For an independent domain check, use fresh Bitbrains machine IDs and keep the dictionaries and maps frozen. Treat these as follow-ups. Check checkpoint availability for independently trained same-model SAE seeds and document any limitation. No test item will be promoted into calibration.

### Forecast addendum

Before inspecting primary numeric outcomes, extend the forecast check to all rank-32 supervised transfer arms. Apply each predicted target-state change in its natural calibrated size. Compare the induced eight-horizon median forecast change with the one induced by the target's actual window-mean change. This reference is a hidden-patch effect; it is distinguishable from the ordinary effect of changing the input history. In Bolt, broadcast a predicted mean displacement to the two native 16-step tokens. This preserves their within-window difference and avoids leaking the target's changed within-window detail. In TimesFM the mean displacement belongs to one native 32-step patch. Zero-edit replay is required. Record paired cosine (zero effect scores zero), reference-aligned gain, RMS error, target effect magnitude and per-item forecast deltas. Report the raw norm and normalized forecast-shape agreement as diagnostics. This battery will run even if no primary advantage appears. Bitbrains random-node telemetry had zero items meeting the preselected full-window rule; use the fast-storage hourly CPU channel, for which at least 80 eligible machines exist. Keep the original M4 fit and validation choices frozen.

### Dictionary seed follow-up

The historical middle-layer checkpoint for each backbone has a single available set of weights. Test two fresh initialization/minibatch seeds (1 and 2) per model, training the repository's baseline ReLU/TopK SAE on exactly the family-stratified public-dev training rows used by the archived run. Reuse the recorded dictionary width (6,144), k (32), augmentation loss, learning rate, batch size, and minimum step count (720). The archived run supplemented 34,515 benchmark windows with 3,990 windows sampled online from Monash. The latter activation rows were not persisted. For the new two-seed comparison, omit augmentation in both seeds, with identical training rows and hyperparameters for that pair. Evaluate the two already-frozen cohorts, sites and doses. This tests reproducibility across the two aligned new training recipes and robustness relative to the archived dictionary. It does not reconstruct the original dataset byte for byte. Because items and research questions are reused, seed runs are sensitivity measurements, not new independent datasets.

### Same-backbone feature identity across seeds

Before inspecting the independently trained pair's joint results, ask whether individual atoms align when both dictionaries see the *same* frozen model and identical hidden changes. Fit one-to-one Hungarian assignments using only the 128 clean M4 calibration histories. Include atoms active at least once there. The primary assignment maximizes decoder-direction cosine in the shared residual space. A secondary assignment maximizes centered clean hard-code activation-profile cosine across the 128 histories. Fit a nonnegative, per-pair least-squares rescaling through zero on calibration clean activations for each code variant. Evaluate each fitted seed-1→seed-2 correspondence on the 80 daily reserve items, with no revised matching. Report support coverage, fraction of clean active IDs successfully matched, cosine of matched clean state codes and matched code-change vectors under hard and shoulder gates, using the complete seed-2 target code as denominator. Randomly permute the matched target indices within frequency-sorted blocks of 16 in eight predetermined runs, preserving the set of target features and roughly their calibration prevalence. In each permutation refit the same per-pair scale. Show differences with paired bootstrap by reserve item. Same-backbone comparisons set the dense reference alignment to exact identity. A weak one-to-one score can reflect distributed or many-to-one representations, support boundaries or the finite calibration sample.

After the first Bolt pair showed high clean-code cosine but much lower edit-code cosine, add a coverage check. Project the *true* target code or code change onto the target atoms represented in the assignment. Its cosine with the complete target is the maximum achievable at this support coverage. Also inspect code deltas when the two SAE supports are each locked to their own clean endpoint. This removes hard selection events in both seeds and uses the same one-to-one assignments and calibration scales. Label the added within-pair contrast exploratory.

### Is the low same-backbone edit agreement caused by one-to-one matching?

Following the first same-backbone feature-pair results, fit many-to-many rank-at-most-32 ridge maps between the independently trained dictionaries, learning from paired *edit differences* on the original 128 histories with the original 48-item validation. Keep the reserve histories for evaluation. For each fixed target code type (hard, shoulder, or locked), compare source hard, shoulder, locked, full dense change and known waveform. Report cosine and scale on exactly the same target. Include maps learned only on clean activations, testing their linear part on an edit. Because the backbone is identical, knowing both absolute hidden endpoints and target SAE weights would reproduce the target codes exactly. The dense-response arm receives only the displacement, so its prediction may depend on the clean state and on the restricted rank. This diagnostic tests linear prediction of another trained dictionary's response, and is conditional on the dictionaries and calibration sizes.
