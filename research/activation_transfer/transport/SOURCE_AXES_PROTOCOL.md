# Can a source-defined hidden direction reproduce its own forecast effect in another model?

Protocol fixed before selecting the evaluation items or running any fixed-axis patch. The earlier natural and waveform comparisons used target-native hidden responses as references. Here the reference is the **source's own intervened forecast**, and the target contributes only clean states during training and its real forecast during evaluation.

Use the same 384 training series, fitted maps, sites, window, checkpoints, horizon and clean-input standardization. Define eight source-only directions. For the first four, take training hidden-state principal axes 1, 4, 16 and 64, orient each by positive largest-magnitude coordinate, and use half its training score standard deviation as the dose. For four named contrasts use the source's mean hidden contrast for the ramp, sine, recent-step and pulse input families on the original 384 training histories, without a target contrast or target forecast. This experiment injects a **fixed** source vector per axis on all evaluation histories; the original input to both models is unmodified.

Evaluate on 128 newly designated M4 daily items with original IDs at or above 2000 and 96 Shenzhen taxi 15-minute items. Select by fixed RNG permutations (2026112121 and 2026112122), excluding the original transport and natural-window manifests, current behavioral control and shape manifests and the direct atom study's declared daily items. Exclude duplicate normalized histories within this experiment. Each item uses its last 128 observations ending 16 before the end. One item is one bootstrap cluster, conditional on these shared time periods; the Shenzhen items are traffic locations with possible concurrent shocks.

Compare the actual positive-minus-negative central patch response on the source with the actual target response to the linearly mapped direction, in clean-history standard deviations. The map is never rescaled using target forecasts. The shared-circuit nulls are (a) a ridge map with shuffled source–target training correspondences and its vector rescaled per axis to the correct mapped norm, (b) each of the other three directions within the same group, applied at the correct mapped norm, averaging the three separate controls' scores (not averaging the forecasts), and (c) a no-target predictor using the mean *source* response per axis over the first 96 training items. This last comparator is a measure of how predictable the source reference already was. All analyses include weak source effects, with the native RMS reported. Report raw and within-horizon-centered shape recovery and cosine, as well as the fraction of across-history residual variation recovered, centering each axis/lead separately. Report per-axis evidence and macro-average with equal weight for the four axes in each group. Compare the bridge with the wrong-axis control using paired series resampling. The new populations are a post-natural-result follow-up; PCA axes have no asserted temporal semantics without a separate labeling experiment.
