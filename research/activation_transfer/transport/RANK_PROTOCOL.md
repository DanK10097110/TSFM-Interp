# How many dimensions of the dense bridge carry its forecast response?

Fixed after the four-waveform study and before scoring the natural-window replication or any rank-compressed interventions. The waveform experiment found asymmetric hidden-delta recovery despite strong forecast-response recovery in both directions. The follow-up asks whether a small set of directions in the clean fitted representation also carries these intervened forecast responses when observed histories slide forward in time.

Use the exact original 384 paired clean daily series, original ridge regularization selection, and original middle-block sites. Compute the right singular basis of *centered fitted destination states on training histories*. Project each transported test edit onto the first 1, 4, 16, and 64 right singular directions, or retain the full map. This is reduced-rank prediction by variation in the fitted clean-state outputs, without forecast supervision. For each candidate rank, project instead onto random orthonormal subspaces of the same dimension within the fitted range. Use two controls: uniform orientation and random draws weighted by the observed fitted-state standard deviations, which favor routinely occupied directions. Form nested random subspaces with three fixed seeds per control. Multiply each randomized projected edit by a positive scalar to match the corresponding principal projection's norm in the same held-out item and shift, so any difference is directional. Save per-seed scores. The three draws offer sensitivity checks rather than inference over all orientations.

Evaluate both signs on the same frozen target median-forecast path. Reference is the response to the native target patch for the observed shifts by one and four steps. Report native-response energy recovery, the effect of removing the within-forecast horizon mean, and across-series within-shift variation separately; also show how much full-map response energy is recovered at each rank. Primary summaries are the per-cohort paired difference in ordinary and horizon-de-meaned target-native recovery between principal and norm-matched random projections. Quantify average control performance by averaging the scores of its individual seeds. Bootstrap original VM or M4 item IDs, recomputing cohort centers when appropriate. The rank grid is descriptive; no rank is selected or tuned using held-out forecast effects. Any rank efficiency can depend on temporal support, clean training distribution, and checkpoint.
