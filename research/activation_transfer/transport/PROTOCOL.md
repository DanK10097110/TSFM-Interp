# Dense transport of localized hidden edits on real histories

Protocol fixed November 20, 2026, before extracting model states or evaluating the edit. A linear map fitted to paired clean hidden states could carry a local edit across architectures even if individual learned dictionary elements differ. The competing explanation is that shared response to input does not imply shared forecast-relevant coordinates.

## Population and intervention

Use frozen Chronos-Bolt-small and TimesFM 2.5 200M and the GIFT-Eval M4 daily and weekly shards. Select one final 128-step context ending 16 steps before each distinct item's last observation. Exclude nonfinite and constant contexts and identical standardized context bytes. Standardize using the clean context's own mean and standard deviation. Use 384 training and 128 held-out daily items from the ordered eligible RNG permutation (seed 2026112001) and 128 weekly replication items (2026112002). Persist the split, data hashes and item IDs. No future values, forecast labels or sealed benchmark corpora enter any fit. Bootstraps treat the original item as the unit. The same historical series may have appeared in the models' pretraining.

Use the median at the first 16 lead times. Fix the input of the middle residual block in each model using the adapter's ordered list at floor(n/2). Represent the final 32 historical steps by concatenating both Bolt patch vectors or taking the last TimesFM patch vector. Exclude Bolt's regression token. The spans match in the original time units, although earlier context and attention patterns can influence their hidden vectors.

On each independently standardized history add or subtract 0.35 times one of four patterns over its last 32 observations. The patterns are a linear ramp from -1 to 1, a sine with period 8 and phase zero, a step on the last eight indices, and a triangular pulse centered on index 16 with half-width four. All other observations stay fixed. For model M define its native edit as half of the difference between positive and negative hidden states. Inject that edit with both signs at the clean history's same site and take half of the difference between median forecasts. This is the reference response of the selected internal site. Measure the full response to editing the history as a separate diagnostic.

## Fit and controls

Fit an affine ridge map between clean paired states in both directions. Use train mean-centering, no coordinate standardization, and choose regularization only from withheld training folds by clean destination-state prediction. The transport of an edit uses just the map's linear part. Scale-sensitive primary results use this prediction as-is. Estimate two controls fitted on the exact same train items: (1) independently shuffled target-training item identities, preserving all marginal state distributions, and (2) a raw-history-to-target-state ridge map applied to the known input waveform. An independent control averages native target edits conditional on perturbation family using only training items. That control observes target contrasts on train, an information advantage over the bridge. A direction-only comparison sets each alternative's vector length to the transported vector length, independently for every sample; the causal reference is always unmodified.

Compare the resulting target-patch response with the effect of the target-native patch. The primary scalar is pooled response recovery across items, four perturbation families and leads: one minus the sum of squared errors divided by the sum of squared target-native responses (a zero edit scores zero; exact equality scores one). Also report horizon-centered recovery, signed pooled gain, pooled raw cosine, individual concept metrics, and agreement with the source-native response. Pool normalized-history forecast units. Bootstrap paired by series, with 4,000 resamples and 95% percentile intervals. Primary support requires positive raw recovery and a positive paired improvement over shuffled pairing in both directions on daily; use weekly as a separate locked population check. Report comparisons against both the raw-history and family-average controls regardless of sign. An accurate hidden map need not identify a shared predictive circuit, and success for this particular native reference need not imply that the source's forecast change transfers. A history-dependent perturbation uses a labeled source activation contrast at test time; this design does not transport a fixed human-named feature.
