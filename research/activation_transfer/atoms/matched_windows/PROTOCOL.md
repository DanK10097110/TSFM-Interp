# Dose-matched natural-window directions and literal atom removals

Local design recorded 20 November 2026, before inspecting the new window effects. Earlier studies here used different sites, maps and response targets for natural-window changes and single-feature ablations. This new experiment compares the two edit classes under the *same* atom-study intervention and evaluation rules. The feature set and the 160 M4 item IDs have already been examined for atom outcomes. This is a controlled follow-up, with no new architecture or domain.

Freeze the exact 1,024 training items, SAE checkpoints, 16 preselected atoms per source, 480-step clean daily test histories, source amplitudes and firing cases from the original TimesFM/Chronos-Bolt atom experiment. That experiment used output block 10 of TimesFM and output block 3 of Bolt, one or two native tokens respectively in the final 32 observed steps, eight median forecast horizons and an affine ridge map fitted to paired centered window means on the 1,024 clean histories. All item and feature IDs and source checksums will be saved in the run manifest.

For each test item, shift the 480-point sliding window backward by one observation if its predecessor exists and is finite. If it is unavailable, shift forward by one only when the first buffered observation is finite. Report fallbacks, exact end indices and unusable cases. Reuse the *original* raw window's float64 external mean and standard deviation for both windows, cast to float32 and replay the same model adapter, including its normal per-forward internal preprocessing. The clean reconstructed standardized histories must match their materialized atom-study arrays exactly. Recapture unshifted hidden tokens, check against the archived vectors, and verify every final-window position and dictionary hash. No observed future value is used as a forecast label or fitting target.

For source series i, define v_i as the adjacent window’s mean final-block-output token activation minus the original mean at the same site. Keep its positive, observed orientation in the chosen shift direction. For every source atom j that fires on the *original* i, let d_ij = z_ij ||w_j|| be the observed removal size from the archived atom vectors. Write d_ij × v_i / ||v_i|| to the source and its frozen-map linear image to the recipient, each added to the intact clean state. Zero-length window displacements are explicitly tracked and assigned a zero write. No target normalization, recalibration or forecast-guided sign choice. The original atom arms are −z_ij w_j and −z_ij T(w_j). Use the original ridge bridge implementation for all new vectors and audit that the 16 previously archived mapped decoder vectors are reproduced. Preserve the original binned token slices and broadcast conventions. Subtract each model’s own intact/zero-patched forecast. Check all active doses, source and target atom forecast replay on the daily subset, and zero-patch drift.

Each edit's reference is the eight-lead response to that edit in the *source model*. On identical active feature/item cases, compare the forecast of the same mapped edit in the recipient to this source forecast change. Compute each atom’s pooled signed cosine, horizon-demeaned signed cosine and the original dose skill 1 − SSE / reference energy, then average atoms equally. A cosine is zero for a zero candidate with a measurable reference. Use the original reference RMS >1e−5 history SD eligibility criterion. If arms have different measurable features, use the intersection for the paired contrast and publish both masks and the ordinary separate-arm score. Use the same 4,000 seeded bootstrap draws of whole histories across all atoms and arms and report two-sided 95% intervals for each arm and for window minus atom. Center forecasts separately per item and arm. Additional diagnostics are reference/candidate RMS, gain, per-feature values, firing counts, zero rows and norm-matching errors. The two source-native references correspond to two distinct intervention directions at matched source dose; this is a question about behavioral transfer, not identical effects of different edits. The natural-window direction is rescaled and written to the original model at a single block; these patch effects differ from the ordinary full-input sliding-window forecast.
