# Can an actual source SAE ablation be reproduced across checkpoints?

Prospective study, 20 November 2026. Earlier experiments succeeded at transporting changes caused by input waveforms. These displacements are drawn from observed input variation. A single decoder atom may instead write in a direction poorly constrained by paired natural states. We therefore test the original question directly by ablating a feature where the source model actually activates it.

**Material.** Frozen TimesFM 2.5-200M and Chronos-Bolt-small, with the existing public-development 6,144-dimensional TopK dictionaries at output blocks 10 and 3 respectively. Context 480, final 32-step window mean (one TimesFM patch or two Bolt patches), eight median forecast steps. Capture in fp32. An edit is added to both Bolt tokens or the single TimesFM token; the clean reconstruction residual and all other token differences are preserved. An item's true value after the context is unused.

**Population.** Take daily M4 real histories by seeded permutation with 1,024 train items for map fitting, 96 for native-effect calibration diagnostics and 160 for evaluation. Use 160 further, genuinely different Monash hourly electricity customers for a locked population test. Retain distinct finite nonconstant standardized contexts; one buffered history per original series. The original forecasters and SAE training corpora may have seen these domains. Electricity-customer intervals condition on the observation period. Do not access sealed repo benchmarks. Commit the selection manifest before scoring.

**Direction selection.** Per model, select up to 16 source atoms by a seeded uniform draw from atoms firing on 5–60% of training histories. If fewer qualify, fill from 2–95% firing; report the exact count and IDs. Neither effects nor test activations influence selection. Train an affine ridge map from clean paired window mean states (penalty 0.01 times largest squared singular value). For each source feature f, its reference counterfactual on a history is removal of its natural contribution, −z_f w_f. The dense transferred intervention on the same history is −z_f T(w_f). Use its unadjusted size.

**Comparisons.** (1) A sham map permutes clean target–source training pairs; match its per-atom direction length to the real map. (2) A wrong-atom control uses the correct bridge with another of the 16 source atom directions, normalized to the true mapped length. Keep the original source amplitude and history. Average four predetermined derangements. (3) Rank nonnegative target-code correlations on the clean training data to find the most coactive candidate target atom and disable its own natural contribution on source-firing evaluation cases. (4) Approximate the dense mapped direction by one, four or sixteen signed target decoder directions using greedy orthogonal matching pursuit over target atoms active on at least 1% of training histories. Fit on vector geometry only. These combinations are signed writes into target decoder space, not natural co-ablation. Test their actual recipient forecast effects against the full dense target write, and separately against the original source ablation.

**Outcomes.** Restrict each source atom to histories where it fires. Compare source and recipient actual one-sided eight-lead forecast changes after subtraction from the clean forecast. Main comparison is signed waveform cosine pooled over active items and horizons per atom, then equally averaged over atoms, versus dose-matched wrong-atom and shuffled-map controls. Report scale-sensitive skill, signed gain, and horizon-centered cosine, retaining all effects above the numerical replay floor. Report screening counts and coverage, including atoms inactive in a new domain. Also report recovery of the *receiving dense intervention* by the target dictionary projections as a separate outcome. Bootstrap whole series together across atoms, conditional on the sampled atoms and fitted map. Check individual effects and leave-one-atom-out sensitivity. A third domain or new training seed is a separate study. A recovered signed direction in the recipient is evidence about a local intervention, not proof of an identical natural feature.

**Identifiability diagnostic, before scoring.** Apply the source-side ridge shrinkage operator P=(XᵀX+λI)⁻¹XᵀX to each source decoder vector, using only centered clean training states. Measure the actual source forecast after ablating this regularized component. The clean map T cannot learn a correspondence orthogonal to its training variation. Comparing the projected source ablation with the full source ablation and the transported target effect measures how much the chosen regularizer changes the source effect before comparison across checkpoints. Small retained norm alone cannot distinguish shrinkage from lack of span coverage. The subsequent unregularized-span audit measures the two separately. Record the retained source direction norm and leave-one-atom-out ranges.

**Scoring rule.** Use 4,000 item-bootstrap draws. For primary directional selectivity, report the 0.625th percentile of each paired improvement in source-reference cosine over the wrong-atom and shuffled-map controls (two ordered pairs × two domains × two controls, Bonferroni one-sided family 0.05), alongside ordinary two-sided 95% intervals. Use zero cosine for a zero candidate with measurable reference. Require at least one firing item and active-item reference RMS above 1e-5 clean-history SD to score a feature for the primary cosine; publish the excluded IDs and measurable fractions. Per-feature and other metrics are descriptive.

**Exploratory uncertainty across feature choices.** The primary interval holds the feature set fixed. A supplementary two-way bootstrap draws evaluation series and selected atom IDs independently with replacement, resampling the same series/feature indices for all arms. Use 10,000 draws, both the original any-firing rule and at least eight firing customers/items. These intervals illustrate sensitivity to the finite set of features within each checkpoint. They hold the map, feature eligibility, dictionary and wrong-feature comparison assignments fixed. Two firing atoms in an external domain provide particularly limited evidence about the broader dictionary.
