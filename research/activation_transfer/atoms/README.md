# Removing a naturally firing source feature

A feature's write is its decoder vector multiplied by its actual activation on that item. Removing only this term preserves the rest of the original hidden state, including everything missed by the SAE. A centered ridge map, trained on 1,024 paired clean daily histories, transports its direction to the other checkpoint. We add the mapped removal while running the recipient. Only the native target coactivation control uses the target feature's own firing amplitude on test histories. No forecast is used to select the atoms, fit the bridge, select coactive candidates or build the target dictionary approximations. [Definitions and pre-specified controls](PROTOCOL.md)

Each source has a 6,144-feature, TopK-32 dictionary. On the 1,024 training histories, 132 Bolt features fired between 5% and 60% of the time, from which 16 were drawn. TimesFM had 14 features in this range. All 14 were used and two were drawn from the broader pre-specified 2–95% range. Both groups were chosen before intervention outcomes were measured. Each arrow uses one SAE and one fixed middle block per checkpoint. The test data are 160 M4 daily series and 160 electricity customers, with 96 separate daily calibration items reserved for follow-ups. Cosine measures signed agreement over the eight leads and active histories within each feature. The reported estimate weights source features equally. Removing the average at each history measures how much of the forecast's *shape* carries over. Full skill penalizes an incorrect size as well as an incorrect direction. TimesFM → Bolt includes 13 of 16 daily atoms with positive full skill despite an average near zero; some poor estimates have large errors. In reverse, several individual source atoms had strongly *opposite* target responses. Each complete record gives per-atom effects and the pre-specified simultaneous bounds on selectivity over the two nulls. The regularized within-source write is an informative positive control. If a second model were an exactly orthogonal reparameterization of the first with the exact inverse before its output, the same ridge fit would recover this shrunken source edit in the original coordinates. Its daily full/centered cosines were .892/.499 in TimesFM and .728/.734 in Bolt. Across checkpoints the shapes agreed much less. The regularizer retained a median decoder norm fraction of .526 for TimesFM and .255 for Bolt. At the stated numerical rank all Bolt directions and a median .967 of each TimesFM direction's norm lay in the unregularized training span. Small retained norm therefore measures considerable shrinkage. We re-expressed captured states in a known coordinate system using a signed permutation and a translation. We reversed that transformation on the intervention vectors before applying them to the live checkpoint. On 32 real daily series, back-transformed directions agreed exactly. Native and fitted forecast replays under this coordinate change differed from the originals by at most 0.00000501 history SD. [Known-coordinate-change check](results/gauge_check.json) An independent audit replayed identical zero-dose batches on all active cases across both checkpoints. Maximum spurious forecast change was 0.00000215 history SD. Even after removing each forecast’s mean, the smallest daily atom-level RMS in the source-native and dense-mapped arms was more than 471 times the largest zero-dose case RMS in its corresponding batch layout. [Independent archived-data audit](../audit.py) For a coactive target feature with exactly zero native activation we score the true removal as zero. This prevents tiny batch-dependent roundoff from acquiring a nonzero direction cosine. ## Reproduction

Use the cached snapshots and archived SAE run specified in the project setup. The driver builds both models’ states, selects features, applies all intervention arms and writes per-item effects and scores into the directory chosen by the caller. Source-selection and intervention results can be rescored using the arrays shipped here. [Setup](../REPRODUCE.md) · [Driver](reproduce.sh)

```bash
bash research/activation_transfer/atoms/reproduce.sh /tmp/tsfm-atoms-fresh /tmp/tsfm-atoms-fresh-results
python -m research.activation_transfer.atoms.scores timesfm --folder /tmp/tsfm-atoms-fresh-results
```
