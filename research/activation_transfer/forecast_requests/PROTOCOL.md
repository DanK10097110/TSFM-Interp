# Can an output-targeted steering direction travel to a third checkpoint?

Prospective follow-up, 20 November 2026. A first fixed-cue experiment found that intervention on the two native final tokens can produce very different magnitudes. Here the source direction is fitted to a **specified forecast change**. This makes “same behavior” testable in common forecast units. No counterpart input perturbation defines the reference.

Use Chronos-Bolt-small, TimesFM 2.5-200M and Timer-base-84M in their existing deterministic adapters. Context 192, median horizon eight. At the inputs to the middle and three-quarter transformer blocks, take the last token on each model's live forecast path. For Bolt it is a registration token, for the other two it is a data patch. Compare roles at those sites; evidence about full architectures would require broader coverage.

One context per nonconstant finite M4 daily or weekly series, ending eight steps before the last value, standardized on its own history. Use new seeded daily series, disjoint partitions of 640 clean histories to fit a centered ridge map across representations, 64 for estimating source controls, 32 for optional target dose calibration, and 128 for evaluation. Use another 128 weekly items without refitting. Exclude exact standardized duplicate contexts across groups. Record all IDs. Prior studies use overlapping populations, so this is a fresh design and split, not independent replication of the family as a whole.

At each site form the top 24 directions of the clean calibration states by PCA. Estimate each frozen model's forecast response to a small symmetric displacement along each direction on the 64 source-calibration histories. Solve for one regularized fixed displacement for each of three equal-RMS targets: lift every horizon, introduce a centered linear tilt, or add a period-eight sinusoid. Each requested RMS is 0.05 history standard deviations. The directions minimize average squared forecast error across calibration histories with a ridge penalty of 0.01 times the maximum squared singular value of the stacked design. Clip the combined displacement to 0.20 times the training median state norm. These are fixed per-model reusable directions, estimated without a particular evaluation history. A model's independently fitted direction is the within-model positive comparator.

For every ordered pair, apply the linear part of a clean-state ridge map to the source direction; use 0.01 times maximum Gram eigenvalue as ridge penalty. Compare the resulting action at its original dose with the native target and with four shuffled-correspondence maps rescaled to the transported norm. For the practical few-shot variant, fit **one nonnegative scalar** per direction using target forecast responses on the 32 designated calibration histories, constrained to [0,8], and replay the scaled intervention in the actual target model. The scalar uses target outputs and must be labeled accordingly. Report whether the same requests could be made natively and whether rescaling fixes magnitude or leaves an error in the eight-step shape.

Primary outcome: one minus sum of squared eight-step errors divided by target energy on real held-out series, against the **specified request**, with positive values indicating improvement over zero edit. Report signed gain, orthogonal collateral, native and shuffled controls; show all model pairs, both depths and all three requests. Aggregate equally over requests. Only interpret failed transport as evidence about portability where the source and target both obtain positive skill natively; report counts and failures for all cases. Conditional 95% paired series bootstrap intervals for preregistered summaries. Causal within a recipient under the intervention; matching an output waveform cannot identify a shared algorithm.

**Matched calibration control.** After observing a large zero-shot dose mismatch, give each of the four shuffled directions the same scalar calibration on the same 32 histories, including the same nonnegative [0,8] constraint and actual replay. Compare calibrated correct vs mean calibrated shuffled losses, resampling the same evaluation series jointly. This checks whether a directional advantage survives giving the shams equal access to target response calibration.
