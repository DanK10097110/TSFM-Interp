# Does a named lock act similarly when applied first and last?

A separate batch-size-8 Bolt run on the frozen cohort showed that the isolated recent-mean input at fixed endpoint and slope produced a small intact daily half-lift, about +.0108. Locking 5432's decoded term removed around +.0198; locking the entire reconstructed difference removed roughly +.108 while restoring exact clean tokens removed about −.0066. This prompted a follow-up on the same 128 M4 daily items, on that one cue and both signs, before evaluating the four new patch types or seeing the separate TimesFM results. It reuses evaluation items and is explanatory.

At the final-window site split the exact intervention restoring clean tokens into three additive hidden vectors. N is the named decoded correction, O is the other part of the clean-minus-edited pooled reconstruction, and R is the remaining per-token difference from the exact clean state. Thus N + O is the original full SAE lock and N + O + R is the original exact token restoration. On both frozen models physically run the four missing combinations O, R, O + R, N + R. Alongside the previous intact, N, N + O and N + O + R treatments this gives all eight subsets. Report the population-average forecast lift removed by each term when applied first and when applied last, and the average incremental change over the six possible addition orders (a Shapley value for this specified three-way partition). Verify these average increments sum to the measured exact-token effect per history. Report intervals by paired whole-history bootstrap and do not interpret a mixed-sign decomposition as percentages of a unique biological or model mechanism. The residual includes both the SAE reconstruction residual and native within-window token differences. Norm-matched controls and held-fixed input statistics remain in the primary experiment.
