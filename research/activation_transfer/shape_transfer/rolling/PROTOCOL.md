# Transferring a source-atom ablation across rolling forecast origins

Frozen before selecting histories, loading their checkpoints or scoring interventions. Select 96 previously unused finite, nonconstant M4 daily series and 96 hourly Monash traffic sensors with at least 520 observations. Exclude the original atom and replication, matched-window, steering, forecast-requests, transport, boundary and tangent manifests used in fresh_cohort; additionally exclude the fresh_cohort and blind_frequency evaluations and exact normalized windows shared with earlier atom/held-out caches. Minimize other known overlap. Each series gets five windows of length 480 ending at offsets 0, 1, 4, 16 and 32 from one initial forecast origin; the last window ends eight observations before the end of the raw series. Fit normalization once on that series' initial 480 observations and use its historical mean/SD throughout, preserving common units without future leakage. Report raw zero-based half-open indices and how far windows change on the shared coordinates. Source and target see identical raw histories; forecasts are compared on their next eight *relative* leads at each new origin, whose actual calendar targets change as the series advances. Reserve future observations; they are never labels.

Keep the same 16 archived source atom IDs, source SAE and receiver SAE, trained middle sites, final 32-observation token group, calibration-derived weighting of level and shape, native signed source removal and original 20%-radius target cap. Rollouts use original naturally positive source atoms; quantify donor survival, new firings and coefficient changes separately. At origin 0 determine the ordinary-input-derivative-selected single signed receiver atom and its executed coefficient. Re-query the imported frozen checkpoints for their states, ordinary eight-lead derivatives and natural source ablation at each observation time. Compare five physically applied single-direction policies at each future origin:

1. Carry the *exact old physical write* with its signed coefficient unchanged; this deliberately tests blind reuse even if that atom no longer fires or the coefficient exceeds the current local budget. Separately score this operation on now-inactive donors. It satisfies the historical receiver-radius cap.
2. Carry the old coefficient with the receiving atom's *current* support and signed coefficient bound enforced. An unavailable atom produces zero. This policy still lacks the new donor state; it can act after the donor stops firing.
3. Keep the original target ID and refit its signed coefficient against the current predicted source change; if either atom is inactive, do nothing.
4. Choose the best one of all 32 currently active recipient atoms and refit its coefficient against the current predicted source change.
5. For diagnosing source waveform drift, use the original source derivative response per unit source coefficient, multiply it by the current natural source coefficient, and use the current receiver derivatives and all 32 candidates. This can change the target ID but does not see the new source derivative.

All selections use predicted clean-state derivatives only; the actual source-removal forecast is reserved for evaluation. Score full and per-wave mean-removed recovery against that origin's *actual* source ablation. Use zero intervention as a common baseline, current source first-order vs actual as a positive control and prior source ablation times the new/old coefficient as a forecast-only diagnostic. Report old winner availability, old-vs-local identity switches and their split into receiver support exit or ranking among surviving features. Report conditional recovery on pairs firing at both origins, and all originally firing pairs (including unwanted stale writes when the donor stops). Each horizon has separate 4,000 paired whole-series bootstrap replicates; no repeated-origin row is an independent series. Primary estimator pools case energy on the matched firing population, with equal-donor macro sensitivity for at least eight persistent firings. Domains, directions and lags reported separately. Compare with the earlier synthetic perturbation results descriptively, without equating input amplitudes. Do not tune lag, IDs, weights or thresholds. The unchanged initial-origin and exact no-op forecast provide positive controls.
