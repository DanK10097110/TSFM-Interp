# Does the hidden-state map preserve the order of the six interior temperature edits?

Frozen before reading any hidden state or forecast produced by the permuted edit. This is an exploratory control proposed after the independent 35-station, eleven-date TimesFM → Bolt ramp-versus-warming-step result. Reuse those 385 histories, original clean archive, two original H16 sites, final 32-observation pool, M4 displacement map and original physical Celsius inputs. No new fitting, station selection, calibration, sign adjustment, or forecast reference from another model.

A is the original eight-day ramp from −2 to +2°C. B takes those identical eight values in the index order [0,6,5,4,3,2,1,7]. Reversing the six interior values preserves both endpoint values, minimum, maximum, mean, variance and total squared edit magnitude. Its interior is falling. The added vector is permuted before addition to the clean history. The final raw history’s variance and the forecaster's normalization can differ because the edit's covariance with the original history can differ.

For each target g ∈ {A,B}, calculate its own isolated native eight- and sixteen-lead response: capture the clean and changed Bolt block-3 mean over both final 16-day observed tokens, add the difference identically to the two clean tokens, and measure the original H16 head. Each donor edit independently changes the TimesFM block-10 hidden state on its last 32-day token. Transfer each change by the original frozen M4 ridge map. For each of the two target references, the same-labeled donor change is applied unchanged; give the opposite-labeled donor vector the length of that same-labeled mapped vector at that station/date. This gives four applied policies. At each goal compare them to the same fixed Bolt reference using the same clean receiving context and target-specific budget. Reuse previously measured A→A only after sample replay and manifest checks.

Primary contrast is the unweighted arithmetic mean of the two target-specific differences in pooled H1–8 horizon-centered squared-error skill (correct minus swapped). Each goal-specific skill uses its own receiving reference energy denominator. Publish each goal-specific difference and each cell; use precisely the previous 3,000 paired crossed station/date resamples, station-only and date-only alternatives, retaining shared bootstrap weights for both references and both interventions. Report H9–16, all H16, full/centered waves, true reference RMS and RMS difference A–B in °C for the full and centered segments, and the individual contrasts. Report between-station variability descriptively only as needed. Report finite errors and three fixed singleton waveform checks. Interpretation is restricted to this one predefined within-window permutation, the isolated middle-block forecast effects and the already viewed station panel.
