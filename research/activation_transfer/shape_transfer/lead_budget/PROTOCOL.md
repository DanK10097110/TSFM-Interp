# Which eight forecast leads are worth measuring?

Following the same-model demonstration that the first eight derivatives can discard later behavior, test one practical alternative at a fixed eight-row observation budget. Use the same 128 M4 daily and 128 traffic histories from blind_frequency, the same naturally active donor SAE atoms, the same middle data-token sites, dose cap and local balanced inverse. The cohorts have previously been studied on median forecasts. The particular lead selection and tests here are prospective.

Fix four audit leads, 9, 11, 13 and 15 (one-based), that are never supplied from the current donor or receiver. Compare the first eight, a simple spread of 1, 3, 5, 7, 10, 12, 14, 16, and a choice of eight out of the same 12 available leads made once using only past donor Jacobians. For the last policy enumerate the 495 possible eight-lead subsets on 96 disjoint daily calibration histories. Use fourfold calibration-only prediction of centered audit derivatives, minimizing squared error averaged over all generic hidden coordinates. Do not select using current receiver writes or held-out ablations. For each choice build a donor-only linear forecast predictor using the 96 calibration histories; compare it with ordinary piecewise linear interpolation. Both forecast-only methods receive exactly the same eight current donor derivative estimates as the physical controller. Learning these predictors requires disclosure of calibration audit rows. The uniform and first-eight physical policies need calibration only for the budget and relative level/shape weight.

The primary endpoint is centered recovery on the four common audit leads, compared on the same histories and active feature set. Also report the *same* first-eight endpoint (where the spread arm sees only four) and all sixteen, to reveal the acquisition trade-off. Finally score centered leads 17–32, unseen by all current controllers, with a donor-only historical linear extrapolator. Collect its 32-lead generic calibration labels before evaluation. Capture actual 32-lead forecasts for each physical source and target intervention, validating the existing first-eight references. A positive result from spreading the queries would show the importance of measurement placement; beating no action alone gives little evidence of a shared hidden mechanism when a same-information interpolator performs as well. Costs refer to independent derivative rows; real decoder calls can emit many horizon coordinates at once.

## Follow-up after the initial lead-placement scores

Interpolation of the same ordinary-state donor readings performed competitively. To ask what the *physical* write carried beyond piecewise straight-line interpolation, subtract each waveform's own interpolation from its four held-out audit values, then center those four errors within the history and active donor feature. This removes both average level and candidate-specific anchor errors. Compare the residual from the actual receiving forecast with the residual of the actual donor removal. As forecast-only competitors, use the fixed donor-only calibration ridge predictions and a natural cubic spline through exactly the same eight derivative estimates. Each predictor receives only the current eight supplied readings. The four evaluation coordinates lie inside the spread and selected sets' outer anchors. This stricter test is exploratory and reuses those same histories.
