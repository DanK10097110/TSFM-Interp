# Eight reusable recipient directions with forward-only feature probes

Locked before collecting forward-only calibration responses, test probe responses or new target interventions. We ask whether eight fixed recipient write directions can copy the current donor feature removal across histories using only forward calls. Retain the two archived original 16-atom dictionaries, actual active coefficients, post-block output sites and tokens covering the last 32 steps of a 480-observation history. Use the previous 1,024 clean M4 daily training histories for PCA and native hidden-norm budgets, 96 separate M4 daily histories for response calibration and 192 reserve daily plus 128 Bitbrains histories for evaluation. Outcomes are the physical donor SAE-removal forecast changes, used only to score estimates. Score frequent features with at least eight firings within each domain. All 16 selected features are probed wherever active.

For each model use the top 24 centered clean-state principal axes, plus a separate 24-axis Haar-orthonormal random hidden span from Gaussian QR with fixed seed 2026112088 (Bolt), 2026112089 (TimesFM). On all 96 CAL series measure eight-lead responses to signed finite probes of 0.002 times training median state norm on each axis, using both signs. This gives a 96 x 8 x 24 gradient approximation using forward forecasts and hidden writes. Set a shared donor-specific mean-versus-centered output weight by measuring the same energy ratio as the differentiable study with its 24 random calibration probes, independent of target basis and donor atom identity. For each span solve the stacked calibration linear system for the 8 generic unit-output waveforms, using ridge 0.001 times the largest squared singular value of the weighted design. The eight directions in native recipient hidden coordinates are fixed across items and source atoms. Use the identical relative penalty rule, active coefficient and 20% recipient norm cap from the original study. Record effective fit and singular spectra.

On each active donor test case, probe along its normalized decoder vector at both signs, centered on its ordinary hidden state. The step is the smaller of 0.002 training median hidden norm and 25% of that example's actual removal norm. Convert the symmetric derivative back to a response per unit source activation, then multiply by negative actual activation. This excludes the true donor removal from the probes. The resulting eight-vector selects a linear mixture of the recipient's eight generic writes. Apply the capped mixture physically on the target, with a clean forecast as reference; no per-item target derivative, source backpropagation or per-goal recipient calibration. Compare both basis spans against a mean-source control: on the 96 donor calibration histories probe all sixteen donor decoder directions at the fixed 0.002 training radius, regardless of firing, then average. This comparator receives the test activation and no test directional probes. For comparison include the independently archived full-dimensional recipient inverse fitted with calibration gradients and the same current-history donor gradient, and quantify accuracy of the finite source estimate against its archived source derivative after deployment.
