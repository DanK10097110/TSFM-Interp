# Does fixed SAE-group substitution replicate beyond MOMENT on a native forecaster?

Registered before computing these matches, group fits, or recipient interventions. Primary checkpoint Chronos-Bolt-small, original archived TopK-32 SAE donor to the independent same-site seed-1 SAE fitted on its historical development activation distribution. Primary cohort 128 pre-existing blind M4 daily histories from the transfer study. Prespecified external-domain checks use the 128 previously frozen Monash traffic histories and 46 USCRN stations at four common dates. These are the same weather histories as the MOMENT study, deliberately paired across architectures; donors/SAEs differ across checkpoints and individual item-level results have previously been used by this project. Use TimesFM as a second checkpoint under the same protocol if feasible. Original archived 16 donor atoms selected using only the original 1,024 M4 training items. Do not change donors if they are silent in a domain. Disclose historical training, test provenance, feature frequency and number of independent items/stations; these are new interventions on existing panels.

All matches and greedy sparse approximations use only the two SAEs' frozen decoders and ordinary paired last-window codes on the 1,024 training cases. Use the final 32 observed time steps: unweighted mean over the last two 16-step Bolt token representations after encoder block 3; one final 32-step TimesFM token after block 10. Rank target atoms by Pearson correlation of raw positive sparse codes; restrict all target candidates to atoms firing on at least 8 M4 training items; tie by target index. Finite interventions use the intact live model, H16 native median head, same final observed token(s) written jointly, same current histories, all original natural source firings. Compare (a) positive-training-correlation counterpart at its own receiving coefficient, including donor-on/receiver-off events; (b) same counterpart with its decoder norm matched to the observed source removal; (c) signed matching pursuit rank 1, 4 or 16 with a least-squares refit at each rank, using source dose times the fixed reconstruction. Donor reference is the archived native atom removal and confirmed against independent native physical runs. No weather, traffic or held-out donor response fits any candidate.

Negative control rotates the complete eligible target decoder dictionary by one seeded global Haar orthogonal matrix (26112301 for Bolt, 26112302 for TimesFM). This preserves target row norms and pairwise angles. Refit rank-16 matching pursuit to each original donor decoder using these rotated rows and the same eligible code IDs, then scale each resulting vector to the norm of the corresponding *real unrotated* 16-axis group. Evaluate actual live rotations at identical hidden budget and donor dose. Seed and rotation shared across all held-out domains within a checkpoint. Report both scaled geometry errors and relative physical outcomes.

Primary outcome is mean donor-feature skill for the horizon-centered native H16 recipient change versus the finite original donor removal, restricted to source firings for each feature; zero is unchanged forecast. Report first-eight and last-eight centered responses separately, full/physical amplitude, pooled-by-reference-energy skill alongside equal-feature skill, eligible/total fires, co-firing and noise. Both lead bands are held out from all training geometry; neither is used to tune. At least 8 distinct series/stations must fire per reported donor, with all origins of a station kept together. Use 3,000 paired series/station bootstraps plus crossed donor resampling. Raw forecasts are in the locally standardized inputs' units on the M4/traffic panels, original Celsius for weather. Convert to observed-history SD for scoring. Record published per-firing native shifts, scores, fit metadata, and independent full-model replay including a zero receiving gate if present. The fixed groups use the observed donor dose, not a detector.
