# Does moving the write or correcting it in place rescue full-dose transfer?

In the 128 original Bitbrains fast-storage VMs, a full natural Bolt removal translated to TimesFM achieved centered skill .903, .348 and .914 at blocks 0, 10 and 19. Prior tests recovered high skill when both actual donor and recipient doses were reduced. Here the source remains at its actual natural removal. The 20% target-state norm limit remains fixed. Distinguish recipient dose error, curvature of the local target map and hard-to-predict donor responses.

Freeze 256 new Bitbrains fast-storage CPU histories, one per machine, before computing study outcomes. Exclude every identifiable fastStorage item in previous public research and in the project's public external benchmark. Preserve the exact exclusion list, IDs, input hash and dataset revision. Each input is the last eligible 480-observation history with an eight-observation buffer, standardized as before. No rolling selection on feature firings. Use the original archived 16 Bolt donor atoms, report all counts, use at least eight firings per atom in each domain, and replay 128 old machines alongside the new cohort. Testing is restricted to the three prespecified TimesFM layers.

Measure (1) the prior open-loop write at full source strength, (2) a budget-constrained scalar search along that *same* target direction, and (3) one feedback correction in a new direction. For each firing case the scalar search physically tries 0, .25, .50, .75 and 1 times the original capped write; select the one whose measured target response is closest in the calibrated level/shape metric to the donor's *ordinary-state linear estimate*. Recompute the recipient Jacobian at the selected hidden state, solve for the remaining discrepancy, project the resulting total write onto the original 20% ball, and test additional step fractions .25, .5 and 1. Permit retaining the preceding response. No candidate or evaluation outcome from a donor removal enters these choices. This is a more expensive per-case controller; the effect used for scoring is always a physical target forecast. Compare measured recipient responses against the actual, unchanged native donor removal. The best single scalar and final iterative method can only improve the target-side selection objective. Either may worsen true donor imitation.

Primary confirmatory comparison is block 19 minus block 10 for the original full-dose controller on new VMs. Next compare scalar versus open loop, and one additional direction versus scalar, at block 10. Report bootstrap intervals clustering by machine, two-way feature/machine uncertainty, actual frequencies and influence of leaving out any one machine. Compare target selection loss with donor-linear accuracy. For explanation, identify how concentrated the earlier failure was and report retained scalar and clipping. The last block may yield cleaner eight-lead control while having a worse unseen continuation; none of these adaptive steps receives a donor goal after lead eight.
