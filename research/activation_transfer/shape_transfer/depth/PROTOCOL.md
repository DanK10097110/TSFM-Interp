# Which receiving layer can write a donor SAE feature’s forecast effect?

Frozen on 21 November before the depth sweep. Keep the donor's naturally firing 16 SAE features, native block, signed dose and eight-lead response fixed. Move only the receiving intervention. Test the first block, one quarter, one half, three quarters and final block in Chronos-Bolt-small and TimesFM-2.5-200m. Patch block *outputs* at the same observed 32-step window in every layer. This is Bolt's final two data patches, excluding its special token, and TimesFM's last data patch. Relative depth is a convention across architectures. The final target site is still internal.

Use the original 1,024 daily histories only for the typical state norm at each site, and 96 disjoint daily histories to calibrate a fixed eight-vector receiver library. The source waveform estimate comes from the donor's current derivative and its natural feature amplitude. Compare this reusable receiver with a receiver allowed its current eight-output derivative. The solver, source-specific training weight and relative damping match the previous full-space study. Apply both at limits of 5% and 20% of the site's median training state norm. The two caps are common fractions; report actual write sizes, clipping, output sensitivity and conditioning because a percentage of state norm does not imply equal control authority. Evaluate both methods by actually intervening on each frozen model. A wrong-lead adaptive control uses the same .20 budget and a lead derangement fixed in code.

Evaluation uses 192 daily and 128 machine histories from the original replication and the already locked additional 128 daily and 128 traffic histories. Datasets are separate in every result. Use the original eight-firing-history threshold per feature/domain; conditional paired whole-series uncertainty for differences. Primary depth contrast is final minus first, separately for fixed and adaptive at 20% and for the full and centered eight-lead source effect. The .05 cap and middle layers are descriptive. Also inspect leads 9–16, unseen by the receiver calibration and local inverse, comparing to actual sixteen-lead donor removals. For a precision check, reproduce the original middle site against its archived state derivatives and physical forecast outcomes. No control or site is fitted on test ablation outcomes.

Later layers might make the fixed controller more consistent across histories or reduce the required write norm. A strong eight-lead score in a late readout could also constrain only the selected leads. Those explanations make different predictions for the fixed-versus-adaptive gap, tight-budget performance and unconstrained continuation.
