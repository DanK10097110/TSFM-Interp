# Is a more informative translation enough for a named forecast request?

Keep the original three *fixed* donor writes and original middle last-token locations on Bolt and TimesFM. Score the existing 128 daily and 128 weekly held-out series. No per-request target calibration. The new bridges use the derivative of the eight-lead response to a last-token write in both checkpoints. A transfer sees the donor vector and generic derivatives. The recipient-native oracle additionally sees the desired eight-lead waveform. Those are different questions.

Cross two factors: (1) one target operator fitted on 64 paired daily FIT histories versus the two checkpoints' local derivatives on the current test history, and (2) translating into 24 clean target PCs versus its full hidden space. The source response is always estimated in full coordinates. Solve in physical units by damped least squares, penalty .001 times squared top singular value and cap each target write at .20 times its median training state norm. Each subspace uses the same relative penalty and physical cap. Use raw eight-lead squared error. Compare the original clean-state transfer with recipient-unit calibration and the independent local recipient goal oracle. Score both fidelity to the actual donor edit and improvement toward the user's requested shape. A third partial-information arm exposes only odd lead derivatives to the adaptive full-space translator and evaluates on the withheld even leads; a shuffled-order control constrains the wrong leads. The ordinary output need not be correct on ground truth for an intervention comparison to have meaning. These tests use time-series histories without future observations.
