# Do two forecasters share an input equivalent for a natural hidden intervention?

Registered November 21, 2026, before inspecting input probes, input edits or their outcomes. Use the archived middle-block SAE donor-removal study's 128 disjoint M4 daily and 128 Monash traffic histories from blind_frequency, 480 standardized observations, same sixteen training-selected features in each direction and their naturally positive donor coefficients. Cohort IDs have appeared in earlier experiments. A primary domain-feature requires at least eight firing histories.

**Common input coordinates.** Choose the first twelve orthonormal DCT-II synthesis modes on the most recent 32 observations, including the constant-on-the-tail component. Other 448 points stay fixed. Work in the original already-standardized observational units; internal model preprocessing remains active. For each model and history use symmetric public forecast calls at plus/minus .02 RMS per basis direction over the final 32 observations. Use only the first eight median leads to build a local input Jacobian. Before scoring, check the finite-difference prediction against an independent jointly oriented plus/minus .01 RMS probe on eight preset histories per domain. Check clean forecast replay against the blind_frequency production archive. All edits are independently bounded to .25 RMS across the last 32 samples (Euclidean norm .25√32, never recalibrate the cap). Save actual postcap skills, saturation and unbounded size. This is a local budget on normalized input, separate from hidden edit sizes.

**Four prespecified input writes.** For each donor atom and history, the target is the local eight-lead median change predicted by the donor's *hidden* Jacobian times the true signed atom removal. Neither its physically measured effect nor leads 9–16 inform the writes. Use the donor's original historical mean/shape weighting, and ridge .001 times the largest singular value squared of the weighted design. Compute the donor-only damped minimum-norm inverse of the donor INPUT Jacobian. Add a norm-matched control that applies the donor-only vector after a fixed derangement/sign transformation of the twelve DCT coordinates. Recipient-aware and joint inverses use respectively only the recipient input Jacobian or stacked donor and recipient input Jacobians with duplicate copies of the same donor goal and equal model weighting. In both cases actual history perturbations, including clipping, are shared between the two forecasting models. Receiver access and actual transplant success are distinct questions.

**Evaluation.** Use actual public forward passes to both models for each of the four edits and subtract the ordinary forecast on identical case/batch layouts. Score these deltas against the donor's *actual nonlinear hidden removal* at leads 1–8 and the unconstrained 9–16, centered within each block and in full. First endpoint is recipient centered early skill for the donor-only history edit, with the corresponding donor self-match and scrambled recipient outcome. Use equal per-source-feature normalized SSE, paired 4,000 resamples of histories and eligible features, linked across methods. Report ordinary two-sided intervals and first-endpoint positive lift over zero and norm-matched scramble with one-sided family bounds .05/8 (two comparisons × four model-domain cells). Report the other arms and late results descriptively. Include the actual early hidden-space minimum-norm map on the same cohort as a higher-access reference from blind_frequency. Validate signs, coefficient scaling, caps, actual state edits, and a sampled independent small-batch production replay. No other input families or cap tuning.
