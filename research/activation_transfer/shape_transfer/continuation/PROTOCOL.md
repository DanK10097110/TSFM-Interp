# Forecast continuation from early constraints

Registered before measuring any new continuation intervention. The prior full-space study found that matching leads 1–8 of a natural source SAE removal reproduced daily forecast shape there but performed poorly on leads 9–16. We test whether a prior supplies useful information about the many receiver writes compatible with those first eight observations.

Use the original Bolt and TimesFM postblocks, token mask, sixteen archived donor atoms per direction, 1,024 clean training items, 96 disjoint M4 calibration items, 192 daily and 128 machine evaluation items. The source physically loses its own naturally occurring coefficient times its unit decoder direction. All target writes receive **that source coefficient** with the same subtraction sign, then one radial cap of 20% of median receiver training-state norm. We reuse the measured source and first-eight minimum-norm receiver 16-step forecasts. Verify that fresh all-16 Jacobians agree with stored first-eight Jacobians and with production two-sided directional probes on all 16 outputs.

Fit the original scalar shape weight using only the 96 source early Jacobians. Within the relevant horizon, weight the horizon-centered residual by this factor and the mean by one. Use the original 0.001-times-largest-eigenvalue damping. With weighted early target design A and weighted early donor response b, solve u = p + A_damped^+(b − A p) before coefficient application and clipping. Because of damping and clipping, the early effects of different priors can differ.

* Use zero prior (original minimum-norm solution), the original clean-hidden ridge mapped donor atom as prior only and with an early correction, and the same correction with four fixed original wrong-atom permutations. Match each wrong donor's mapped prior norm to the correct prior before the correction. Compare correct to the mean of the four independently scored wrong-prior interventions.
* Fit a second prior on 96 calibration histories by one stacked ridge solve matching 16 weighted generic local derivative rows between models. Applying the same linear rule to each donor decoder direction requires no measured feature-ablation labels. Evaluate this fixed prior alone and after the early correction. Only the first eight local Jacobian rows from evaluation may enter either corrected-prior solve.
* Compare to a zero-prior 16-lead oracle that sees both live models' local derivatives on all sixteen leads for each evaluation input. It uses the identical weighting rule, scalar weight, damping and radial cap. Its derivative access on leads 9–16 measures recipient controllability using privileged information. Actual donor counterfactuals and observed future values are evaluation-independent of every solve.

Measure skill relative to predicting zero donor effect, using actual nonlinear receiver forecasts and stored actual source removal forecasts. Score leads 1–8 and 9–16 separately both in full and after subtracting the eight-lead within-window mean. Within each model/domain, include atoms with ≥8 positive source firings, equal-weight their energy-normalized skills, and bootstrap held-out histories together across arms, conditional on these atoms. Four domain/direction cells times two candidate priors give eight primary comparisons of corrected prior vs zero-prior **late centered** skill. Report paired 95% intervals and Bonferroni one-sided 0.00625 lower bounds for positive gains. Report early paired changes, prior-only comparisons, wrong-prior contrasts, oracle effects, active counts, actual write norms and clipping. Use the unchanged machine/daily samples even if coverage is sparse. No parameter or prior selection from evaluation performance.
