# A common receiver vocabulary, exploratory follow-up

Registered after the first TimesFM→Bolt fresh results showed positive cross-donor and level-only performance, and before fitting any common-vocabulary list or computing its test response. Existing evaluation cohorts are explicitly reused. A disjoint same-size availability null may remove ubiquitous target atoms, and permuting learned lists can retain some donor-conditional coverage. Ask whether a *single global list of at most four IDs* can serve all donors.

Use the same calibration cases, decoder directions and expected single-atom signed gains. On each of the original 16 donors divide all candidate gains by the sum of the unrestricted maximum gain across its firing calibration cases, then concatenate all normalized rows. Greedy addition defines the common weighted-response vocabulary. Every donor has equal attainable total objective. Also fit the same level-only global objective and a frequency baseline taking the four largest unconditional calibration firing counts (ascending feature ID breaks ties). Freeze all three sets. On both fresh domains compare each to the existing personalized shortlist and unrestricted local measured responses. Give all lists the same bounded signed current-history response solver. The contrast tests one four-feature vocabulary per recipient versus three or four IDs per *donor*, whose union can be substantially larger. It does not test how many features a receiver needs for arbitrary tasks.

Descriptive follow-up specified after the shared-vocabulary causal scores: on the already fixed sparse-stability pairs, count whether both unrestricted winners of a paired identity change appear in the four common receiver IDs, with the original common control sets, at both frozen noise doses. This reuses the archived unrestricted IDs and requires no new selection or physical treatment. It asks whether the common four-ID vocabulary also accounts for the observed identity switches.

After counting moderate-noise exact switch containment (zero of 95 Bolt-source pairs and three of 35 TimesFM-source pairs in the common functional list), make one same-case physical check. Execute just the already frozen common functional list on the original 96 histories and their 2% perturbations. On the cases where the unrestricted identity switched, compare actual common-list, donor-specific and unrestricted writes on each waveform against that history's true source ablation. Give pooled-energy full and centered scores and paired whole-series uncertainty with denominators; label this secondary switched-case analysis explicitly. No new target IDs, corpus or fitted parameter is introduced.

For interpreting the switched-case numerical result, show the subset where neither the clean nor the perturbed unrestricted winner belongs to the shared functional list, reusing the same interventions. This distinguishes genuine substitute choices from cases where the global list happens to contain one side's best ID.
