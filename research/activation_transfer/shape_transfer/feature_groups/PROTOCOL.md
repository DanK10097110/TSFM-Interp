# Does a small functional shortlist transfer across histories?

Frozen before fitting lists or examining shortlist outcomes. Use all original 16 preselected source atoms per model and the original 96 held-out calibration daily series. A list is specific to a donor and an ordered checkpoint pair. Four IDs are alternative one-atom writes, not simultaneous edits or a partition of a dictionary. Use only calibration clean-input forecast derivatives, target and donor SAE coefficients and original weighted eight-lead forecast loss in discovery. Keep original natural source feature removal, signed receiver coefficient bounds, 20% hidden-radius cap and local signed one-atom implementation. At test, shortlist membership is frozen and the recipient atom and dose are selected locally among its currently positive members. No available member gives zero. Reproduce original one fixed and all-32 local policies.

For each firing calibration case and recipient atom, compute the optimal bounded one-atom improvement in weighted squared response error predicted by the two checkpoints' ordinary-input derivatives (using the original pre-cap pursuit for identity selection). Among all atoms ever available when this donor fired, greedily add the atom with greatest incremental improvement over the best member already in the set. Stop at four members or when no positive incremental improvement remains. One member reproduces the earlier fixed signed partner. Compare to (i) fitting the same greedy set using forecast level alone, with the full weighted solver on evaluation, and (ii) four calibration-matched sham lists with the same number of members. Each sham excludes the functional members, matches their calibration joint and per-member availability when the donor fires and unconditional per-member prevalence. Generate shams by seeded search over candidate IDs seen on calibration, without accessing response derivatives or evaluation histories. Report achieved calibration and held-out availability; estimate paired effects on cases where both functional and matched lists are available to distinguish coverage from waveform choice.

Primary evaluation is the independent 128 daily histories of the frozen fresh-cohort replication. Report 128 hourly traffic histories separately as a distribution shift, with coverage limits. Compute the actual causal forecast changes under signed one-feature edits, full and per-history horizon-centered recovery of the source's actual ablation. Primary estimator follows the original equal-atom recovery among donors firing on at least eight histories per domain; report firing counts, uncertainty via 4,000 whole-history paired bootstrap replicates, and pooled squared-error recovery as sensitivity. Report number of cases with an available shortlist member and proportion containing the actual unrestricted best ID. For the four matched shams average their scores and bootstrap draws. Independent questions are whether the list improves over a fixed atom, exceeds the matched shams and the level-fit list (especially on centered shape), and how much performance it loses against unrestricted current derivatives.

Reuse the first 96 daily histories and their paired 0.1% and 2% observational-noise variants from sparse_stability. For all source cases active on both inputs, count exact unrestricted winner changes and how often the original and new winners are both among the donor's four learned IDs, with all switched cases as denominator. Compare to matched-sham and level-only list inclusion. Measure shortlist availability and exact restricted winner agreement conditional on both inputs allowing an edit, excluding shared no-ops. On moderate-noise and clean inputs physically apply the frozen list and all-32 comparator and compare their real forecast recovery. This is a local stress test on previously used raw histories with new test arms. The fresh cohorts were unseen by shortlist fitting but had been used to evaluate dense intervention policies. Do not tune group size or metric after seeing evaluation scores.

Before fitting, add a donor-permutation control to account for shared ubiquitous atoms that the disjoint matched lists cannot use. Reassign whole learned lists one-to-one to other donors with equal list size, minimizing on calibration the squared differences in conditional and unconditional set availability plus sorted member frequencies. Identical lists owned by different donors are legitimate assignments. Document any donor with no distinct size-matched owner and exclude that comparison for it. This control and the same-size disjoint shams have complementary availability tradeoffs.

For the shared-availability analysis, require eight jointly available firing histories for a donor in that domain, then compare arms only on its jointly available rows. Report any resulting change of atom population and the event-pooled sensitivity, especially when frequent daily source atoms disappear on traffic.
