# How reproducible are the shortlist IDs under refitting?

Exploratory calibration-only diagnostic registered after seeing fresh waveform and noise-containment results. Before scoring split fits, generate 40 seeded random equal partitions of the original 96 calibration series. Fit the original greedy functional shortlist separately on each disjoint half without evaluation outcomes. Within each donor report first-choice agreement and Jaccard overlap of the fitted ID sets, plus a distinct-donor comparison using other eligible donors on the opposing half with the same learned-list cardinality when available. Report donors with at least two firings on each half, and a stronger four-per-half sensitivity. For the single shared functional vocabulary, refit on each half with equal donor normalization wherever that donor has support. Summarize across the 40 split-specific mean agreements and 10th–90th percentiles. These are descriptive training split ranges using the same 96 histories, not independent-sample confidence intervals or forecast comparisons. No new receiver forecast measurements are involved.
