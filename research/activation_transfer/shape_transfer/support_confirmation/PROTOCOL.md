# Prospective daily receiver-support test

The earlier Bolt donor → TimesFM receiver swap preserved short-budget forecast recovery while retaining a median 28–29/32 feature identities on the earlier blind daily histories. We will test the reverse receiver, which has a less recurrent support, and repeat TimesFM under identical rules. This protocol precedes new model captures, support selection and forecast scoring.

Select 160 new GiftEval M4 daily source identities, seeded 20261122011, one 480-step standardized history per identity, an unused eight-observation trailing buffer. If fewer than 160 eligible disjoint series exist use all remaining rather than reusing an earlier source. Freeze both a source-ID list and normalized input hash before any model measurement. Audit named prior maps/train, calibration, test, rolling, rotated/gated/fresh/blind studies, previous confirmation and the external benchmark. Exclude data even when a later experiment used a different window of the same series. No threshold or hyperparameter changes after scoring. A model’s original SAE training may involve large pretraining corpora for which original item identities are unavailable.

Its linearized eight-lead effect is the target for all span-constrained searches. At the exact same dense-vector *budget*, each arm solves the same regularized inverse in its 32-dimensional orthonormalized span, then clips to the actual dense displacement norm. Log realized lengths. Apply all edits to the original receiving model on the current history. Physically remove the native donor atom to define a separate donor reference. The measured edited donor/recipient waves and leads 9–16 do not enter any fit or choice of support.

Thus these supports are nested and have matched cardinality; changing own-ID count may change axis orientation and popularity. Features are measured before any hidden intervention.
