# Fixed steering vectors across depths

Frozen before inspecting outcomes, 20 November 2026. The experimental unit is one original series. This experiment uses the existing steering model and its internal additive interventions. It extends the previous two-checkpoint contrast pilot by giving a recipient an edit estimated from the source through clean paired activations.

- **Models and sites.** Chronos-Bolt-small and TimesFM 2.5-200M, float32, CPU, context 64, median forecast of length eight. Capture the input to the blocks at floor(0.25 L), floor(0.5 L) and floor(0.75 L), using zero-based indices. Pair corresponding fractions as a coarse depth comparison. Edit the final representation token at each block. For Bolt this is its registration token and for TimesFM it is its final data patch. This is a functional site comparison; the parallel local transport study aligns actual time spans. Require a successful batch-versus-single and zero-edit replay.
- **Samples.** Use a seeded permutation of eligible distinct GIFT-Eval M4 daily series, taking the final 64 observations before an eight-observation buffer. Standardize by each clean context. Use 512 series for clean state alignment, another 96 for estimating the fixed cue directions, another 96 for evaluation. Replicate without refitting on 96 M4 weekly series. Train and evaluate within this experiment using disjoint IDs. Other experiments using M4 are complementary analyses of overlapping source populations.
- **Cues.** For the recent reversal use the final 32-step triangular dip followed by recovery. For oscillation use an eight-step sine over the final 32 steps. Both leave the final observed value unchanged. On the 96 cue-fitting rows use ±0.35 clean-context standard deviations of each cue. The fixed direction for each model/site/cue is the mean positive-minus-negative hidden state divided by two. Target-native cue directions serve as comparators only.
- **Map.** Fit a centered ridge map on the 512 paired clean states, with penalty 0.01 times the largest squared singular value of the centered source. Apply its linear part to the source direction. No perturbed target states or forecast labels enter this fit. For each direction, also fit eight maps after independently permuting correspondence between the clean target and source series. Compare direction selectivity at equal norm by rescaling these sham edits to the transported edit's norm. Report the recovered native direction's norm and cosine as diagnostics; primary transferred edits retain their estimated scale.
- **Measure.** Apply positive and negative fixed vectors through the steering hook on the *same* clean receiving histories; take half the difference of their eight-step forecasts. Measure both (i) agreement with the **target-native** edit and (ii) agreement with the **source-native** forecast response for the same series. Primary endpoint is target-native response skill, one minus squared error relative to the zero-effect prediction. Report signed cosine after removing each forecast’s horizon mean, relative amplitude, mean level and confidence intervals obtained by resampling series conditional on fitted vectors. Report the paired advantage over the mean of the eight shams. Compare all three depths; avoid picking a winner from the evaluation scores and claiming independent validation. For pooled inference, average contrasts equally over direction and cue within a series. Provide calibration-sensitive skill and a history-specific diagnostic subtracting the across-series response template.
- **Interpretation.** A transported direction which beats dose-matched shams can contain information specific to the alignment. A successful recipient-native match alone says little about whether the source and receiver use the cue similarly. Check the size of each native effect; near-zero denominators make relative scores unstable. A result on controlled edits to standardized histories does not establish forecast accuracy on unmodified data.
