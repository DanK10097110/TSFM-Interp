\section{Measurement Methods}
\label{sec:methods}

Throughout, $x\in\mathbb{R}^{T}$ is a context ($T=512$ in the case study), $y\in\mathbb{R}^{H}$ its
continuation ($H=64$), $\hat y$ a point forecast and $h^{(\ell)}$ the residual stream after block $\ell$.

\subsection{Behavior, geometry and perturbation (L0--L3)}
\label{sec:l0}
\label{sec:l1l2}
\label{sec:l3}

\paragraph{L0.} Accuracy is MASE \citep{hyndman2006mase} per series, with the seasonal lag from ground truth
and a scale floor on the naive denominator, without which intermittent series spuriously improve
(\fid{MN-23}); sMAPE, pinball loss \citep{gneiting2007scoring} and calibration are reported alongside. Pairs
are compared by a paired series bootstrap per family, Holm-corrected across all pairs and families
\citep{holm1979}, and read against each model's repeat-run noise floor. \texttt{budget} measures parameters,
FLOPs, latency and captured-FLOP share; \texttt{frontend} tests scale equivariance, NaN handling and
quantization before any layer runs.

\paragraph{L1, L2.} For aligned, window-pooled and centered activations $A,B$ over the same series, linear
CKA \citep{kornblith2019cka} $\|B^{\top}A\|_F^2/(\|A^{\top}A\|_F\|B^{\top}B\|_F)$ is computed for every layer
pair of every model pair, with a cluster bootstrap and a shuffled-series null. L2 fits ridge maps between
layers and reports only the \emph{gain} over an input-feature baseline, since much of any layer is linearly
predictable from the input. Cluster agreement uses AMI \citep{vinh2010ami}. These claims are
\ev{geometric} or \ev{linear-translatable}.

\paragraph{L3.} For each corruption $c$, the sensitivity \emph{fingerprint} is the relative activation change
$\|h^{(\ell)}(c(x))-h^{(\ell)}(x)\|/\|h^{(\ell)}(x)\|$ per layer, and the \emph{restoration curve} is the
fraction of forecast damage undone by patching clean activations of layer $\ell$ (whole, or per window) into
the corrupted pass. Models are compared by rank-correlating fingerprints on shared relative depth, never by
transplanting activations. Restoration is \ev{causal within-model}; cross-model agreement is correlational.

\subsection{Depth}
\label{sec:depth}

A skip lens decodes the forecast from each layer through the model's head and a tuned ridge lens
\citep{belrose2023tuned} fits per-layer readouts; \texttt{internals} reports effective dimension, family
decodability and CKA to the input. The depth axis is the fraction of the \emph{whole} stack, including
uncaptured parts, so Chronos-T5's last captured block sits at 0.478 (\fid{DE-04}); and the lens is withheld
for a model whose head reads positions the patch never writes, where it would return a flat, meaningless
curve (\fid{DE-03}).

\subsection{Causal concepts}
\label{sec:concepts}

\paragraph{Sparse dictionaries.} Each target layer gets a TopK SAE \citep{makhzani2013ksparse,gao2025topk},
$z(h)=\operatorname{TopK}(W_e(h-b_d)+b_e)$, $\hat h=W_d z(h)+b_d$, with searched dictionary size, an auxiliary
loss reviving dead atoms and a minimum step count (\fid{MP-03}). Since single seeds are not reproducible
\citep{paulo2025seeds}, replicate dictionaries give a within-model reproducibility ceiling (\fid{MP-04}).

\paragraph{The ablation battery.} Feature $i$ is tested on the $k$ series where it fires most, by comparing
the forecast under the reconstruction with $z_i=0$ against the full reconstruction:
\begin{equation}
  \Delta_i^{(c)}(x) = g_c\big(f(x;h^{(\ell)}\!\leftarrow\!\hat h_{-i})\big) - g_c\big(f(x;h^{(\ell)}\!\leftarrow\!\hat h)\big),
  \label{eq:ablation}
\end{equation}
where $g_c$ is one of nine forecast channels (trend, seasonal strength, spectral centroid, level, dispersion,
near/far-horizon shape distance, MASE, flatness). Using the reconstruction as baseline keeps the SAE's error
from being charged to the feature. The null removes a random code direction of matched magnitude on the
\emph{same} rows; a feature clears channel $c$ if mean $|\Delta_i^{(c)}|$ exceeds the null's 95th percentile
$q_{95}^{(c)}$, and its channel vector is $v_i^{(c)}=\overline{\Delta_i^{(c)}}/q_{95}^{(c)}$. Shape channels are
distances and are treated as undirected. A \emph{reach probe} first requires self-patching to change the
forecast by exactly $0.0$ and cross-layer patching by a relative $>10^{-3}$; otherwise the target is withheld
with its reason (Figure~\ref{fig:battery}).

\paragraph{From features to concepts.} Causal features are grouped at three granularities. \emph{Per-target
concepts} cluster one layer's vectors with $k$-means, choosing $k$ by silhouette
\citep{rousseeuw1987silhouette} among values whose smallest cluster has $\ge$3 members (without it, the four
highest silhouettes on the reference run, 0.607--0.717, were all one-outlier splits; \fid{SH-20}); a target with no admissible $k$ is \emph{non-modular}. The
\emph{atlas} pools features from all models and layers and cuts a complete-linkage dendrogram at cosine 0.9,
so an atlas concept is a shared causal-effect profile. \emph{Families} are a coarser readable tiling (average
linkage, cosine 0.5), tested against a column-shuffle null and titled deterministically from their channels.

\subsection{Two notions of sharing}
\label{sec:sharing}

``Shared'' is two questions, answered separately. \emph{Same inputs}: concept transfer asks whether a feature
in another model separates a concept's top-$k$ series from the rest (AUC), against stratum-matched random
subsets, in both directions (\emph{reciprocal} if both clear), with Benjamini-\allowbreak Hochberg
\citep{benjamini1995fdr} per ordered model pair and leg. Input agreement between concept parts is top-$k$
overlap (hypergeometric), never whole-series correlation: two sparse features can have $\rho=0.80$ with no
shared top series (\fid{MN-19}). \emph{Same effect on the same inputs}: every reciprocal-FDR transfer is
ablated on both sides on the same series set $U$; each side must clear its own null on $U$, and level
concordance and shape cosine must beat both sides' activation-matched random-feature floors. Falling below the
floors' 5th percentile is ``acts differently''; merely failing the 95th is ``no specific agreement''
(\fid{MN-18}).

The report combines these into a six-rung ladder per concept (\texttt{report/derived.py}): L1 same forecast
effect (atlas), L2 same inputs, L3 reproducible across SAE seeds, L4 other dictionaries select the same
inputs, L5 same causal effect on the same inputs, L6 confirmed on private data. Each atlas concept also gets a
\texttt{sharing\_class}: \emph{shared} (same effect and inputs), \emph{partially shared}, \emph{convergent}
(same effect, different inputs) or \emph{single-model}; a part is provenance-driven when $\ge$80\% of its top
series come from one real-derived generator.
