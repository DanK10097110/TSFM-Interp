\section{The \tool{} System}
\label{sec:architecture}
\label{sec:principles}

\tool{} consists of two separately installable packages (Figure~\ref{fig:overview}). \texttt{tsfm\_benchmark}
generates, audits, seals and validates corpora; \texttt{tsfm\_lens} loads checkpoints through adapters, runs a gated
pipeline of analysis stages and renders the report. Usage is described in Appendix~\ref{sec:usage}.

\subsection{Design principles}

Each principle is enforced in code as a gate, a refusal or a test, so that a measurement that cannot be trusted is
withheld with a stated reason rather than reported.
\begin{description}[leftmargin=1.2em,font=\normalfont\bfseries,itemsep=1pt]
\item[P1. Ground truth by construction.] Every probe is first validated on a case whose answer is known.
\item[P2. Alignment is measured, not declared.] Token spans are measured from impulse responses, and cross-model
  analysis happens only on a common time axis.
\item[P3. Causal claims need a null, a reach control and a same-seed baseline.] Every intervention is compared with a
  random intervention of matched size on the same series, and sampled models are seeded identically in compared calls.
\item[P4. The series is the unit of inference.] All intervals and $p$-values resample whole series.
\item[P5. Explore, then confirm once.] Registered dev claims are tested once on a sealed split.
\item[P6. Every claim is typed.] Each finding carries an evidence class and a generated caveat, and unsupported
  analyses are skipped with a rendered reason.
\end{description}
The evidence classes are \ev{behavioral} (input--output only), \ev{descriptive}, \ev{illustrative}, \ev{geometric}
(representational similarity), \ev{linear-translatable} (one representation linearly predicts another beyond an input
baseline), \ev{causal within-model} (an intervention changes the forecast beyond a null), \ev{predictive} (internals
forecast a model's error without being shown to cause it) and \ev{held-out confirmed}.

\subsection{Controlled benchmark generation}
\label{sec:benchmark}
\label{sec:layout}

Real data enter the benchmark only as leakage references, for realism calibration and as raw material for explicitly
labeled generators. The \emph{synthetic} tier touches no real data and has exact ground truth: an additive
\texttt{parametric} generator (trend, multiple seasonalities, AR noise, changepoints, anomalies, random walk,
intermittency, heteroskedasticity) and \texttt{random\_parametric}, which draws a recipe from one of eight frozen
archetypes. The \emph{real-derived} tier (\texttt{mixture}, \texttt{block\_bootstrap} \citep{kunsch1989block},
\texttt{sequential\_par}) inherits its source distribution and has attributional ground truth only. Every sample carries
its tier label, so every analysis can be split by tier.

Every sample passes a two-stage leakage gate against the Monash archive \citep{godahewa2021monash} (a prefilter followed
by banded DTW; \citealp{sakoe1978dtw}) and a cross-split near-duplicate check. Dev and private splits use disjoint seed
ranges, every sample is hashed so that loading a sealed split detects any change, and fresh private \emph{epochs} are
minted by striding the seed space. A validation package measures diversity in catch22 feature space
\citep{lubba2019catch22} by participation-ratio dimension \citep{gao2017pr} and nearest-neighbor tails, and tests dev/private
exchangeability with an energy-distance test \citep{szekely2013energy} and per-feature TOST equivalence
\citep{schuirmann1987tost}. Nine structured \emph{corruptions} (noise, detrend, deseasonalize, frequency shift, level
shift, spike, smooth, warp, dropout) drive the perturbation analysis, and \emph{generator counterfactuals} move one
generative parameter along a dose ladder with every other random draw held fixed.

\subsection{Model adapters}
\label{sec:adapters}

An adapter exposes loading, a \texttt{predict} method returning point and quantile forecasts in the original scale, the
underlying module, a forward pass and the time span of each token. Its \emph{capability tier} is derived from the methods
it implements: 0 (black box), 1 (observable hidden states with token spans), 2 (steerable, so patching is possible) and 3
(decomposable attention). Stages above a model's tier are skipped with the missing method named in the report, and a
model whose tokens are measured not to be time-localized is routed to behavioral analysis. A zero-code adapter for
Hugging Face checkpoints discovers layers and measures token spans; it reproduces the spans of all six hand-written
adapters exactly and recovers Timer's 96-step tokens from measurement alone (\fid{MP-01}). Two of the seven models
studied here use it.

\subsection{Time alignment across architectures}
\label{sec:alignment}

A 480-step context is 480 tokens in Chronos-T5 and Time-MoE, 30 in Chronos-2, Sundial and Chronos-Bolt, 15 in TimesFM
and 5 in Timer, so raw token positions cannot be compared across models. We first measure each token's time span $I_j$
by injecting an impulse at every time step; a token's span is the contiguous set of steps it responds to most, accepted
only if it passes a peak-to-pedestal contrast gate ($\ge4$) and a contiguity gate ($\ge0.95$). We then place every
model's tokens on one grid of windows $W_w=[wL,(w+1)L)$, $L=32$ steps (Figure~\ref{fig:alignment}). A token shorter
than a window contributes to it in time order, a token as long as a window maps to it one to one, and a token longer than
a window (Timer's) is copied to every window it spans, never split. A window's representation is the concatenation of
its tokens in time order,
\begin{equation}
  \tilde h_w = \big[\,h_j\,\big]_{I_j\subseteq W_w},
  \label{eq:pooling}
\end{equation}
which loses nothing. Linear CKA needs only the row Gram matrix, and the Gram matrix of a concatenation is the sum of the
per-position Gram matrices, $K=\sum_p X_pX_p^{\top}$, so the long vector is never formed. The common alternative,
averaging a window's tokens, discards within-window order: in the first block of Chronos-T5-Base a window's slope decodes
with $R^2=0.13$ from the window mean and 0.96 from finer sub-windows, while a TimesFM token keeps it. On held-out data
the average understates TimesFM's similarity to the fine-token models by 0.30--0.43 CKA (Section~\ref{sec:rq2};
\fid{MN-38}). Series-level vectors are means over the 15 windows.

\paragraph{What is compared across models.} Alignment fixes the \emph{rows} of two models' activations, not their
coordinates: row $(s,w)$ of every model describes series $s$ over steps $W_w$, but widths range from 384 (Time-MoE) to
1{,}280 (TimesFM) and no axis of one model corresponds to an axis of another. Every cross-model measure is therefore
defined on the shared rows. \emph{Geometry} (CKA, and representational similarity analysis, RSA, on series summaries)
compares how rows relate to one another within each model. \emph{Stitching} fits a linear map from one model's rows to
the other's and reports only its gain over a map from input features. \emph{Concept transfer} compares which
\emph{series} a feature fires on, and \emph{causal effects} are measured on the forecast. Patching never moves
activations between models. Sparse dictionaries are fit to one model at a time and compared only through series
identities and forecast effects, so their comparison does not depend on the window representation.

Two limits remain. The grid is no finer than the coarsest token: within a 96-step span Timer has one vector, so an
alignment check can attribute an impulse to the right window at most one time in three, and hit rates are normalized by
this attainable ceiling (\fid{MP-02}). And $L=32$ is a convention: re-pooling to 64 and 96 steps leaves concept transfer
and the size of geometric similarity almost unchanged but moves the peak layer pair for 12 of 21 model pairs
(\fid{SH-23}), so peak locations are reported as window-dependent. During extraction an \emph{alignment gate} injects an
impulse into each window and checks, layer by layer, that the matching window responds most, with the amplitude
calibrated per checkpoint and context length. Deep layers of Sundial, Time-MoE and Timer lose time localization, which
the report shows next to window-level claims about those layers.

\subsection{The stage pipeline and the report}
\label{sec:stages}
\label{sec:report}

An analysis is a pipeline of 19 stages that write typed artifacts (Figure~\ref{fig:stages}). Each stage declares the
configuration keys it depends on, and these are fingerprinted, so a changed setting invalidates exactly the dependent
cached artifacts. Three gates record their decisions, which the report names as skip reasons: the \emph{tier} gate, the
\emph{run-shape} gate, which drops comparison stages for a single model, and the \emph{routing} gate. Every intervention
goes through a single patching primitive, which raises an error if the model silently splits a batch.

The deliverable is one self-contained HTML file, written so that a reader without interpretability training can follow
it while an expert can audit every number; the seven-model example report is in \repodir{examples/panel7_v2}. Each stage opens with a card stating its question,
method, what good and bad results look like and what it cannot show, and every figure carries an expandable explanation.
The summary scorecard is computed from the artifacts by printed rules with no model names hard-coded: each row shows a
value, the reference it is compared with (a null, floor, ceiling or baseline) and the rule that yields the verdict. Every
claim is a typed record with its evidence class and a generated caveat.
