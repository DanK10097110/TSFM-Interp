\section{Controls Change Conclusions}
\label{sec:controls}

How can a reader know a system is better than a careful script running the same methods? Our answer is a
record of cases in which the obvious analysis gave a well-formed, plausible and wrong answer, raised no error,
and a specific control caught it. Table~\ref{tab:controls} lists fifteen; every control runs by default.

\paragraph{Three failure classes.} \emph{Interventions that never landed} (rows 1--4) produce flat curves or
tables of zeros that read as strong negatives; the remedy (P3) is nearly free: self-patch exactly 0.0,
cross-patch nonzero, two unpatched predictions identical, front end consistent with peers. \emph{Nulls that were
too weak} (rows 5--10) produce inflated positives that look like success (30 of 30 concepts transferring); the
remedy is a null matched on the right confound, on the same rows, bounded from both sides, with the lower tail
for claims of difference. Row 10 is caught by a known answer the system ships: a forecaster whose concepts, decoys and a non-planted control layer are planted analytically, scored against a gate fixed in advance (false-positive rate $\le$0.10, sensitivity $\ge$0.5) on seeds held out from any tuning. \emph{Metrics that did not measure what they were named for} (rows 11--15) are caught
only by validating on a known answer (P1): an untrained twin, a random rotation, known spans, a replicate seed.
Smaller cases include a headline ``reconstruction improves the forecast'' result that replicated in 1 of 5 seeds
(\fid{MN-16}), and a grounded language model narrating features that produced a new class of unsupported claim
after each of four guard passes, while 6 of 6 deterministic sentences were correct (\fid{MN-06}); \tool{}
therefore composes every report sentence deterministically. The table is a set of counterexamples rather than a
benchmark, and it lists only failures that were caught; the verification standard (\repo{CONTRIBUTING.md})
requires each new test to be shown failing against a planted regression.
