How this report was constructed

Distinct float32 contexts were sampled without replacement using the run seed. Discovery measures intervention responses on calibration contexts and selects sites on validation contexts. Full-horizon context policies directly define their target by rerunning the model with the configured input change. Their agreement checks implementation. Each evaluation replays the intervention. A verified case requires a nonzero target, relative L2 error within the configured tolerance across all steps and channels (unsteered error is 100%), and replay agreement within relative tolerance 1e-5 and absolute tolerance 1e-6.
