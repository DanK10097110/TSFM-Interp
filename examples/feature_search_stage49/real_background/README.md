# Real-background pilots: Section 49.23 experiments 2–6

[Open the results](index.html). Five preferred experiments ran on Chronos-Bolt
small and TimesFM 2.5 200M using the same 24 hourly source series from three
cached datasets. Twelve sources fit diagnostics/SAEs, twelve evaluate them.
All ten model/experiment cells completed; none passed its frozen expansion gate.
These are empirical pilot decisions, not confirmatory hypothesis tests.

The useful distinctions are:

- Units/scaling: both models remain nearly equivariant under the tested changes.
- Interaction: internal features do not consistently beat the input-only controls.
- Transfer: donor effects beat random controls, but natural-response and oracle
  normalization closure gates fail. This is an inconclusive mechanism test,
  not proof that component effects cannot transfer.
- History: longer context has uneven benefits; the permuted-prefix control
  fails the discontinuity check. No isolated useful-history claim follows.
- SAE: overall activation reconstruction looks good, but response reconstruction
  does not pass. Feature-label variation cannot establish semantic instability.

Native work used one CPU thread, offline cached checkpoints, and no GPU. The
controllers took 25.226434530050028 seconds for Bolt and 63.65477888402529 seconds
for TimesFM. Neither model exceeded the frozen 3 GiB/900-second per-worker cap.
No larger run or extra training was launched. Ideas 1/7/8 stay parked; 7/8 still
lack their required mechanism/diagnostic evidence.

From the repository root, using the project environment:

```bash
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
export PYTHONPATH=tsfm_lens
python -m experiments.feature_search.real_background_poc prepare \
  --out tsfm_lens/runs/real_background_NEW
python -m experiments.feature_search.real_background_poc run \
  --out tsfm_lens/runs/real_background_NEW
MPLCONFIGDIR=/tmp/tsfm-matplotlib python -m experiments.feature_search.real_background_report \
  --run tsfm_lens/runs/real_background_poc492306 \
  --out examples/feature_search_stage49/real_background
```

`prepare` reads local cached Arrow files and safetensors; it does not download.
Pass `--cache` to use a different Hugging Face cache. It refuses existing output
directories, freezes checkpoint/data/code hashes and selects sources without
looking at future target values. The controller gives each model its own process
and terminates a worker on its memory/time limit. Fresh offsets are supported for
future registered studies, but are not an authorization to bypass failed gates.

The static report intentionally refuses a positive result: its closed-screen
narrative must be revised for any future positive study. Audit scope is explicit:
short-history, transfer, scaling and SAE functional losses are replayed from
saved waveforms; history decisions use stored source losses because unmodified
long/control forecasts were not retained. SAE reconstruction and geometry
checks are producer diagnostics, not independently regenerated by this audit.
Raw captured states, forecasts and SAE weights remain in the run directory.

Validation: 24 focused/geometry/smoke tests passed; each of the six new tests
caught its corresponding planted regression. The existing smoke test emits a
PytestReturnNotNoneWarning. `mutation_checks.json` maps each plant to its test.
See ROADMAP §49.24–49.25 and FINDINGS MN-46/PM-24 for the exact results.
